# Tarhak (طرحک)

کامپوننت‌های متحرک React و میکروتعامل‌ها — ساخته‌شده با Motion و Tailwind CSS.

- سایت: [tarhak.ir](https://tarhak.ir)
- گیت‌هاب: [MiladJoodi/Tarhak](https://github.com/MiladJoodi/Tarhak)
- نویسنده: [Milad Joodi](https://www.linkedin.com/in/joodi/)

## نصب کامپوننت

در `components.json`:

```json
{
  "registries": {
    "@tarhak": "https://tarhak.ir/r/{name}.json"
  }
}
```

سپس:

```bash
npx farsiui@latest add @tarhak/discrete-tabs
```

## توسعه

```bash
npm install
npm run dev
```

## راه‌اندازی

در ریشهٔ پروژه `.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "tarhak": {
      "url": "https://tarhak.ir/api/mcp"
    }
  }
}
```

یا در **Cursor Settings → MCP** همین URL را اضافه کنید:

```text
https://tarhak.ir/api/mcp
```

بعد Cursor را Reload کنید تا سرور `tarhak` Connected شود.

## ابزارها

| ابزار | کار |
|--------|-----|
| `tarhak_list_components` | لیست کامپوننت‌ها |
| `tarhak_search_components` | جست‌وجو |
| `tarhak_get_component` | جزئیات و وابستگی‌ها |
| `tarhak_install_command` | دستور نصب CLI |

## نصب کامپوننت

MCP فقط دستور می‌دهد؛ در پروژهٔ خودتان اجرا کنید:

```bash
npx farsiui@latest add @tarhak/<slug>
```

## لوکال (اختیاری)

با `next dev`:

```json
{
  "mcpServers": {
    "tarhak": {
      "url": "http://localhost:3000/api/mcp"
    }
  }
}
```

Stdio از کلون ریپو:

```bash
npm run mcp:install
```

```json
{
  "mcpServers": {
    "tarhak": {
      "command": "npx",
      "args": ["tsx", "mcp/tarhak-mcp-server/src/index.ts"],
      "env": {
        "TARHAK_SITE_URL": "https://tarhak.ir"
      }
    }
  }
}
```

## عیب‌یابی

| مشکل | کار |
|------|-----|
| Connected نمی‌شود | URL را چک کنید؛ Cursor را ری‌استارت کنید |
| ابزار صدا زده نمی‌شود | چت Agent + Reload MCP |
| کامپوننت نیست | `tarhak_search_components`؛ فقط آیتم‌های `/r` |

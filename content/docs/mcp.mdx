با MCP طرحَک، ایجنت می‌تواند کامپوننت‌ها را جست‌وجو کند و دستور نصب بدهد. آدرس سرور برای همهٔ کلاینت‌ها یکی است:

```text
https://tarhak.ir/api/mcp
```

## Cursor

### از تنظیمات IDE (پیشنهادی)

همان مسیری که برای روشن کردن بقیهٔ MCPها استفاده می‌کنید:

1. **Settings** → `Ctrl + ,` / `Cmd + ,`
2. بخش **MCP** (یا **Tools & MCP** / **Customize → MCP**)
3. **Add new MCP server** با نوع **Remote / URL**
4. آدرس بالا را بگذارید؛ نام مثلاً `tarhak`
5. سوئیچ را **روشن** کنید تا **Connected** شود  
   اگر وصل نشد: Reload روی همان ردیف، یا ری‌استارت Cursor

بعد در چت **Agent** بپرسید مثلاً: «کامپوننت آپلود فایل طرحک را پیدا کن و دستور نصبش را بده.»

### با فایل

**پروژه** — `.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "tarhak": {
      "url": "https://tarhak.ir/api/mcp"
    }
  }
}
```

**سراسری** — `%USERPROFILE%\.cursor\mcp.json` (ویندوز) یا `~/.cursor/mcp.json`  
بعد به Settings → MCP برگردید و سوئیچ را روشن کنید.

## Claude Code

در ترمینال (خارج از سشن چت):

```bash
claude mcp add --transport http tarhak https://tarhak.ir/api/mcp
```

برای همهٔ پروژه‌ها:

```bash
claude mcp add --transport http --scope user tarhak https://tarhak.ir/api/mcp
```

یا در `.mcp.json` ریشهٔ پروژه — برای Claude Code حتماً `type` بگذارید:

```json
{
  "mcpServers": {
    "tarhak": {
      "type": "http",
      "url": "https://tarhak.ir/api/mcp"
    }
  }
}
```

وضعیت: `claude mcp list` یا داخل سشن `/mcp`.

## Codex (OpenAI)

با CLI:

```bash
codex mcp add tarhak --url https://tarhak.ir/api/mcp
```

یا در `~/.codex/config.toml` (یا `.codex/config.toml` پروژهٔ trusted):

```toml
[mcp_servers.tarhak]
url = "https://tarhak.ir/api/mcp"
```

وضعیت: `codex mcp list`.

## OpenCode

با CLI:

```bash
opencode mcp add tarhak --url https://tarhak.ir/api/mcp
```

سراسری: فلگ `--global` را هم بگذارید.

یا در `opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "tarhak": {
      "type": "remote",
      "url": "https://tarhak.ir/api/mcp",
      "enabled": true
    }
  }
}
```

وضعیت: `opencode mcp list`.

## ابزارها

| ابزار | کار |
|--------|-----|
| `tarhak_list_components` | لیست کامپوننت‌ها |
| `tarhak_search_components` | جست‌وجو |
| `tarhak_get_component` | جزئیات و وابستگی‌ها |
| `tarhak_install_command` | دستور نصب CLI |

## نصب کامپوننت

MCP فقط دستور را پیشنهاد می‌دهد؛ در ترمینال پروژهٔ خودتان اجرا کنید:

```bash
npx farsiui@latest add @tarhak/<slug>
```

## لوکال (اختیاری)

اگر سایت طرحَک را با `next dev` بالا آورده‌اید، به‌جای URL بالا بگذارید:

```text
http://localhost:3000/api/mcp
```

Stdio از کلون ریپو (بیشتر برای Cursor / کلاینت‌های command-based):

```bash
npm run mcp:install
```

```json
{
  "mcpServers": {
    "tarhak": {
      "command": "npx",
      "args": ["tsx", "mcp/tarhak-mcp-server/src/index.ts"],
      "env": {
        "TARHAK_SITE_URL": "https://tarhak.ir"
      }
    }
  }
}
```

## عیب‌یابی

| مشکل | کار |
|------|-----|
| Connected / فعال نیست | URL را دقیق کپی کنید؛ سرور را Reload یا کلاینت را ری‌استارت کنید |
| Claude Code سرور را رد می‌کند | در JSON حتماً `"type": "http"` باشد |
| ابزار صدا زده نمی‌شود | حالت Agent را چک کنید؛ یک‌بار لیست MCP را رفرش کنید |
| کامپوننت پیدا نمی‌شود | `tarhak_search_components`؛ فقط آیتم‌های منتشرشده در `/r` |

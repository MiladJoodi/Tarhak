با MCP طرحَک، ایجنت می‌تواند کامپوننت‌ها را جست‌وجو کند و دستور نصب بدهد. آدرس سرور برای همهٔ کلاینت‌ها یکی است:

```text
https://tarhak.ir/api/mcp
```

## نصب با CLI

در ریشهٔ پروژه:

```bash
npx @tarhak/cli@latest mcp
```

CLI تشخیص می‌دهد Cursor، Claude Code، Codex یا OpenCode هستید و کانفیگ همان کلاینت را می‌نویسد (پوشهٔ لازم را هم می‌سازد). اگر چیزی مشخص نباشد، Cursor + Claude + Codex را آماده می‌کند.

برای Cursor بعد از آن Settings → MCP و سوئیچ tarhak را روشن کنید.

## نصب دستی

اگر ترجیح می‌دهید خودتان کانفیگ کنید، بخش کلاینت را باز کنید:

<DocsCollapse title="Cursor">

### از تنظیمات IDE

1. Settings → MCP (یا Tools & MCP)
2. Add new MCP server با نوع Remote / URL
3. آدرس بالا را بگذارید؛ نام مثلاً tarhak
4. سوئیچ را روشن کنید تا Connected شود

اگر وصل نشد: Reload روی همان ردیف، یا Cursor را ری‌استارت کنید.

### با فایل

پروژه — `.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "tarhak": {
      "url": "https://tarhak.ir/api/mcp"
    }
  }
}
```

برای همهٔ پروژه‌ها همان محتوا را در mcp.json داخل پوشهٔ .cursor کاربر بگذارید (ویندوز: کنار پروفایل کاربر؛ مک/لینوکس: خانهٔ کاربر). بعد Settings → MCP و سوئیچ tarhak.

</DocsCollapse>

<DocsCollapse title="Claude Code">

```bash
claude mcp add --transport http tarhak https://tarhak.ir/api/mcp
```

سراسری:

```bash
claude mcp add --transport http --scope user tarhak https://tarhak.ir/api/mcp
```

یا در `.mcp.json` ریشهٔ پروژه (حتماً type را بگذارید):

```json
{
  "mcpServers": {
    "tarhak": {
      "type": "http",
      "url": "https://tarhak.ir/api/mcp"
    }
  }
}
```

وضعیت: claude mcp list یا داخل سشن /mcp.

</DocsCollapse>

<DocsCollapse title="Codex (OpenAI)">

```bash
codex mcp add tarhak --url https://tarhak.ir/api/mcp
```

یا در config.toml:

```toml
[mcp_servers.tarhak]
url = "https://tarhak.ir/api/mcp"
```

وضعیت: codex mcp list.

</DocsCollapse>

<DocsCollapse title="OpenCode">

```bash
opencode mcp add tarhak --url https://tarhak.ir/api/mcp
```

سراسری: فلگ --global را هم بگذارید. یا در opencode.json:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "tarhak": {
      "type": "remote",
      "url": "https://tarhak.ir/api/mcp",
      "enabled": true
    }
  }
}
```

وضعیت: opencode mcp list.

</DocsCollapse>

## ابزارها

| ابزار | کار |
|--------|-----|
| tarhak_list_components | لیست کامپوننت‌ها |
| tarhak_search_components | جست‌وجو |
| tarhak_get_component | جزئیات و وابستگی‌ها |
| tarhak_install_command | دستور نصب CLI |

## نصب کامپوننت

MCP فقط دستور را پیشنهاد می‌دهد؛ در ترمینال پروژه اجرا کنید:

```bash
npx @tarhak/cli@latest add <slug>
```

## لوکال (اختیاری)

اگر next dev را بالا آورده‌اید:

```text
http://localhost:3000/api/mcp
```

Stdio از کلون ریپو:

```bash
npm run mcp:install
```

```json
{
  "mcpServers": {
    "tarhak": {
      "command": "npx",
      "args": ["tsx", "mcp/tarhak-mcp-server/src/index.ts"],
      "env": {
        "TARHAK_SITE_URL": "https://tarhak.ir"
      }
    }
  }
}
```

## عیب‌یابی

| مشکل | کار |
|------|-----|
| Connected نیست | URL را دقیق کپی کنید؛ Reload یا ری‌استارت کلاینت |
| Claude Code رد می‌کند | در JSON حتماً type برابر http باشد |
| ابزار صدا زده نمی‌شود | حالت Agent؛ یک‌بار لیست MCP را رفرش کنید |
| کامپوننت پیدا نمی‌شود | فقط آیتم‌های منتشرشده در /r |

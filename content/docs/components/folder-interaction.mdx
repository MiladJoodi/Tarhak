## نحوه استفاده

```tsx
import FolderInteraction from "@/components/folder-interaction";

export default function Example() {
  return <FolderInteraction />;
}
```

## قابلیت‌ها

- کلیک برای باز شدن: یک ضربه درپوش را روی محور X می‌چرخاند.
- بادبزن اسناد: سه برگه با کمی تأخیر به چپ، وسط و راست می‌پرند.
- نور داخلی: جیب با سایهٔ درونی مثل یک غلاف واقعی خوانده می‌شود.
- جلوی مات: درپوش با بلور و سیلوئت SVG سفارشی.
- کلیک دوباره برای بستن: برگه‌ها جمع می‌شوند؛ درپوش پایین می‌آید.

## نحوه استفاده

```tsx
import DiscreteTabs from "@/components/discrete-tabs";

export default function Page() {
  return <DiscreteTabs />;
}
```

## قابلیت‌ها

- تب غیرفعال دایرهٔ فشرده (`شعاع ۴۰`)؛ فعال پنل کوتاه (`شعاع ۲۰`) با برچسب `text-xl`.
- سطح `bg-background` / `bg-card`، `border-border`، آیکون Hugeicons ۲۴.
- فنر مشترک با `filter-interaction`؛ بدون سایهٔ سنگین.
- مناسب نوار ابزار، هدر تنظیمات یا سوییچ بخش.
- به `motion`، `@hugeicons/*` و `clsx` نیاز دارد.

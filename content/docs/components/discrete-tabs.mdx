## قابلیت‌ها

- **اول آیکن، بعد نام**: تب‌های غیرفعال جمع‌وجور می‌مانند؛ فعال صندوق، برنامه‌ریز یا هشدارها را نشان می‌دهد.
- **چیدمان مشترک**: قرص با فنر جابه‌جا می‌شود تا همسایه‌ها نپرند.
- **درخشش هنگام انتخاب**: هایلایت کوتاه روی تب فعال می‌آید و می‌رود.
- **گلیف سفارشی**: صندوق، تقویم و زنگ SVG داخلی‌اند — عوض کردنشان آسان است.
- **بدون زیرخط شلوغ**: حرکت خودش نشانگر است؛ نوار کروم دوم لازم نیست.

## نحوه استفاده

برای سوییچ حالت کوچک، نه صفحهٔ محتوا. سه تب نقطهٔ شیرین است. پنل‌ها را خودتان زیرش بگذارید — این فقط کنترل است. در نوار ابزار، هدر تنظیمات یا کروم شبیه ایمیل جا می‌شود.

```tsx
import DiscreteTabs from "@/components/discrete-tabs";

export default function Page() {
  return <DiscreteTabs />;
}
```

## کجا استفاده شود

- نوار ابزار ایمیل یا صندوق
- برنامه‌ریز در برابر هشدار در برابر صندوق در اپ بهره‌وری
- هدر فشردهٔ تنظیمات
- کروم بالای اپ موبایل
- سوییچ بخش داشبورد

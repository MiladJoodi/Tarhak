---

## قابلیت‌ها

- **خواندن، بعد نوشتن**: پیش‌فرض یک برچسب آرام است؛ مداد ورودی را بیدار می‌کند.
- **انتخاب هنگام ویرایش**: فوکوس روی فیلد می‌رود و مقدار را هایلایت می‌کند تا بتوانید بازنویسی کنید.
- **مداد به تیک**: دکمهٔ انتهایی از ویرایش به ذخیره تبدیل می‌شود.
- **حلقه وقتی فعال است**: حلقهٔ فوکوس فقط هنگام ویرایش دیده می‌شود.
- **یک کنترل**: بدون مودال جدا، بدون «ذخیره» اضافه در نوار ابزار.

## نحوه استفاده

برای نام، هندل و مقادیر تک‌خطی مناسب است. تیک را به ذخیره وصل کنید. در ردیف فرم یا هدر پروفایل بگذارید. برای متن بلند استفاده نکنید — آن کار textarea است.

```tsx
import SaveInput from "@/components/inline-edit";

export default function Page() {
  return <SaveInput />;
}
```

## کجا استفاده شود

- تنظیمات پروفایل و حساب
- تغییر نام فضای کاری یا پروژه
- جداول ادمین با عنوان‌های درون‌خطی
- مراحل آنبوردینگ «انتخاب هندل»
- فیلد نام نمایشی در صورتحساب

## قابلیت‌ها

- **تب‌ها داخل کاشی**: داشبورد، مدیریت، گفتگوها، منابع — همه در یک سلول بنتو.
- **پیش‌نمای زنده**: نمودارهای کوچک، لیست افراد و ردیف‌های گفتگو تا مثل محصول واقعی حس شود، نه ماکت.
- **نشان شمارش**: اعداد شبیه نخوانده روی تب‌هایی که کار منتظر دارند.
- **مورف لایه‌آوت**: متن هدر و بدنه با انیمیشن نرم عوض می‌شوند، نه برش سخت.
- **کروم شیشه‌ای**: بلور، حاشیه و نوار فشردهٔ افزودن/جستجو تا سطح اپ خوانده شود.

## نحوه استفاده

این یک اسنپ‌شات بازاریابی از محصول است، نه داشبورد واقعی. برچسب تب‌ها و پنل‌های داخلی را با اپ خودتان عوض کنید. صحنهٔ مرکزی حدود ۴۲۰px عرض بدهید — می‌خواهد مثل یک کاشی در بنتو حس شود، نه صفحهٔ کامل.

```tsx
import BentoCard from "@/components/bento-card";

export default function Page() {
  return (
    <div className="h-screen flex items-center justify-center">
      <BentoCard />
    </div>
  );
}
```

## کجا استفاده شود

- کاشی‌های «محصول را ببین» صفحهٔ اصلی SaaS
- گرید قابلیت کنار سلول‌های بنتو دیگر
- صفحات قیمت که فضای کار را پیش‌نمایش می‌دهند
- پست‌های تغییرات یا لانچ
- لندینگ سرمایه‌گذار یا لیست انتظار

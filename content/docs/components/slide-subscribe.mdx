## قابلیت‌ها

- **انتخاب پلن**: سالانه، ماهانه و سازمانی با حاشیهٔ متحرک مشترک.
- **کشیدن برای تأیید**: دسته باید تمام مسیر را برود — نه فقط یک ضربه.
- **متن درخشان**: متن مسیر هنگام کشیدن عوض می‌شود.
- **پایان کار**: بعد از باز شدن، تیک و دکمهٔ داشبورد.

## نحوه استفاده

`onUnlock` را به API پرداخت یا شروع آزمایش وصل کنید. مقادیر و طول آزمایش را در `pricingOptions` عوض کنید. عرض ستون را نزدیک ۳۸۰px نگه دارید.

```tsx
import SlideSubscribe from "@/components/slide-subscribe";

export default function Page() {
  return <SlideSubscribe />;
}
```

## کجا استفاده شود

- دیوار پرداخت و ارتقا
- شروع آزمایش در آنبوردینگ
- تسویهٔ شبه‌موبایل
- تأیید تغییر پلن
- قفل قابلیت‌های پرو

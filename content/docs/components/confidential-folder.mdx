## قابلیت‌ها

- **برش شست**: سوراخی روی لبهٔ غلاف تا نامه همیشه دیده شود.
- **ورق نیمه‌بیرون**: صفحهٔ کرم‌رنگ در حالت استراحت کمی بیرون است تا معلوم شود چیزی داخل است.
- **بیرون کشیدن و چرخش**: روی پوشه کلیک کنید — نامه بیرون می‌آید، برمی‌گردد و جلو می‌نشیند.
- **جلد مدار**: بیضی‌ها روی زغال، با عنوان کوتاه و یک خط توضیح.
- **یادداشت تایپی**: روی جمع‌شده خلاصه است؛ پشت، یادداشت جلسهٔ بسته.

## نحوه استفاده

یک پوشه، یک نامه. عنوان، زیرعنوان، نشان، پیام و جملهٔ پایانی را عوض کنید. زمینهٔ تیره و کلیک لازم است — نه سوایپ، نه پشته. برای افشا استفاده کنید، نه ناوبری.

```tsx
import ConfidentialFolder from "@/components/confidential-folder";

export default function Example() {
  return <ConfidentialFolder />;
}
```

## کجا استفاده شود

- هیروهای «نگاهی به داخل» آژانس
- صفحات تیزر لانچ
- صفحات استخدام یا فرهنگ سازمانی
- جلد کیس‌استادی با افشا
- میکروسایت دعوت یا رویداد

## نحوه استفاده

```tsx
import ExpandableGallery from "@/components/expandable-gallery";

export default function Example() {
  return <ExpandableGallery />;
}
```

## قابلیت‌ها

- پشتهٔ پراکنده: سه عکس چرخیده و روی هم، مثل چاپ روی میز.
- از کشف تا شبکه: با کلیک پشته به گالری کامل باز می‌شود.
- لایه‌بندی مشترک: تصاویر هویتشان را هنگام جابه‌جایی از پشته به سلول حفظ می‌کنند.
- بلند شدن با هاور: هر چاپ قبل از باز شدن شبکه واکنش نشان می‌دهد.
- کلیک بیرون: با کلیک بیرون دوباره جمع می‌شود.

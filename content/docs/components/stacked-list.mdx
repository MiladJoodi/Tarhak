## قابلیت‌ها

- **پیش‌نمایش پشته‌ای**: چند آواتار و نام در حالت جمع‌شده.
- **تبدیل به فهرست**: با باز شدن، بقیهٔ تیم از همان کارت بیرون می‌آید.
- **جستجو در هر دو حالت**: فیلتر بدون ترک ویجت.
- **نشان نقش**: مدیر پروژه، طراح، داده، تولیدکننده — با رنگ جدا.
- **وضعیت آنلاین**: حضور در پیش‌نمایش تا حس تیم زنده بدهد.

## نحوه استفاده

آرایهٔ `ALL_MEMBERS` را به افراد خودتان (نام، نقش، آواتار، وضعیت) وصل کنید. نمای جمع‌شده فعال‌ها را نشان می‌دهد؛ باز کنید برای همه. عرض متوسط کارت لازم است. جستجو و افزودن را به دادهٔ خودتان وصل کنید — دمو محلی است. مناسب سایدبار یا هدر پروژه.

```tsx
import StackedList from "@/components/stacked-list";

export default function Page() {
  return <StackedList />;
}
```

## کجا استفاده شود

- سایدبار پروژه یا فضای کاری
- ویجت تیم روی داشبورد
- تنظیمات دعوت / اعضا
- فهرست‌های انجمن
- پنل «چه کسانی روی این فایل هستند»

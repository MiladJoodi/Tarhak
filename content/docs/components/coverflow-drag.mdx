---

## قابلیت‌ها

- **کشیدن برای مرور**: درگ اشاره‌گر با اسنپ فنری به نزدیک‌ترین کارت.
- **عمق**: کارت‌های خارج از مرکز کوچک، پایین و تیره‌تر می‌شوند.
- **حلقه**: دسته دور می‌زند تا بتوانید مدام بکشید.
- **حلقهٔ فعال**: کارت جلو حاشیه با `foreground` نگه می‌دارد.

## نحوه استفاده

به صحنهٔ بلند نیاز دارد (دمو ۴۸۰px است). آرایهٔ `images` را عوض کنید. اگر عکس‌ها اندازهٔ دیگری دارند، `DRAG_DIST` و `X_OFFSET` را تنظیم کنید.

```tsx
import CoverflowDrag from "@/components/coverflow-drag";

export default function Page() {
  return <CoverflowDrag />;
}
```

## کجا استفاده شود

- انتخاب بازیگر یا تیم
- مرور پروفایل یا دوستیابی
- لوک‌بوک

## نحوه استفاده

```tsx
import Component3dBook from "@/components/3d-book";

export default function Example() {
  return <Component3dBook />;
}
```

## قابلیت‌ها

- بادبزن صفحات: پانزده برگ از یک لولای چپ می‌چرخند، هر کدام با زاویهٔ کمی بازتر.
- دنبال کردن جلد: جلد قرمز «دفترچه» با اشاره‌گر از بسته تا کاملاً باز حرکت می‌کند.
- نور عطف: هایلایت‌های داخلی و جلد پشت نقطه‌دار ضخامت کتاب واقعی را می‌رسانند.
- کشیدن یا هاور: کشیدن اشاره‌گر روی لمس؛ باز شدن با هاور روی دسکتاپ. رها کنید تا بسته شود.
- بدون WebGL: فقط تبدیل‌های سه‌بعدی CSS — سبک برای صفحهٔ بازاریابی.

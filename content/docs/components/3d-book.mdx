## نحوه استفاده

```tsx
import Component3dBook, { Book3D } from "@/components/3d-book";

export default function Example() {
  return <Book3D title="دفترچه" />;
}
```

## قابلیت‌ها

- فنر نرم: باز و بسته شدن با spring تا حرکت اشاره‌گر نرم و بدون پرش حس شود.
- بادبزن صفحات: چهارده برگ کاغذخط‌دار با زاویه‌های پلکانی از لولای راست.
- جلد پارچه‌ای: گرادیان عنابی، بافت پارچه، عطف شیاردار و برچسب «ورق بزن».
- هاور و کشیدن: روی دسکتاپ با هاور دنبال می‌کند؛ روی لمس با drag. رها کنید تا با فنر بسته شود.
- دسترس‌پذیری: فلش چپ باز، فلش راست / Escape بسته؛ `prefers-reduced-motion` فنر را تیز می‌کند.
- بدون WebGL: فقط CSS 3D و Motion — سبک برای صفحهٔ بازاریابی.

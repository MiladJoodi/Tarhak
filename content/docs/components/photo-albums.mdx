## قابلیت‌ها

- **جلدهای پشته‌ای**: سه عکس بادبزنی می‌نشینند، بعد به شبکهٔ آلبوم مورف می‌شوند.
- **بقیه می‌روند**: آلبوم‌های دیگر محو می‌شوند تا فقط بازشده بماند.
- **عنوان مشترک**: نام آلبوم با `layoutId` همراه می‌آید.
- **بلند شدن با هاور**: پشته‌ها کمی کج می‌شوند.

## نحوه استفاده

`COLLECTIONS` را با آلبوم‌های خود عوض کنید. روی پشته بزنید تا باز شود، برگشت برای بستن. والد را طوری نگذارید که overflow را ببرد و مورف قطع شود.

```tsx
import PhotoAlbums from "@/components/photo-albums";

export default function Page() {
  return <PhotoAlbums />;
}
```

## کجا استفاده شود

- اپ عکس و رول دوربین
- دفترچهٔ سفر
- فهرست کیس‌های پورتفولیو
- مودبورد
- انتخابگر آلبوم خصوصی / عمومی

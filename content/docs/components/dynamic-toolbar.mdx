---

## قابلیت‌ها

- **دو سینی**: صندوق ورودی، پیام‌ها، نقاشی، برچسب‌ها در صفحهٔ اول؛ تصویر، بایگانی، بارگذاری مجدد، حذف در صفحهٔ دوم.
- **عرض دنبال محتوا**: با اندازه‌گیری مرزها قرص رشد و جمع می‌شود، نه فضای خالی اضافه.
- **بلور روی درز**: آیکون‌های لبه هنگام تعویض نرم می‌شوند تا برش تند نباشد.
- **پیکان صفحه‌بند**: جلو/عقب بین دو مجموعه ابزار جابه‌جا می‌کند.
- **خطر آخر**: حذف قرمز است و در صفحهٔ سرریز می‌نشیند، نه در نگاه اول.

## نحوه استفاده

مثل نوار شناور ادیتور رفتار کنید. آرایه‌های `primaryTools` / `secondaryTools` را عوض کنید. صحنهٔ کوتاه و عریض با ارتفاع کافی لازم است تا پیکان‌ها برخورد نکنند. هر آیکون را به اکشن وصل کنید — دمو فقط بصری است.

```tsx
import DynamicToolbar from "@/components/dynamic-toolbar";

export default function Page() {
  return (
    <div className="flex h-[200px] w-full items-center justify-center">
      <DynamicToolbar />
    </div>
  );
}
```

## کجا استفاده شود

- کروم بوم یا ابزار طراحی
- ادیتور ایمیل یا یادداشت
- نوار حاشیه‌نویسی تصویر
- نوار «اقدام سریع» ادمین
- پوستهٔ نمونهٔ اپ

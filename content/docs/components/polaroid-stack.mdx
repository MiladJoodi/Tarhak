## قابلیت‌ها

- **پشتهٔ آرام**: همان اندازه، قاب سفید، پای ضخیم پولاروید، روی مرکز روی هم.
- **بادبزن CSS**: هاور یک کارت پشته را از ۵۴° تا −۵۴° می‌چرخاند. بدون Motion و بدون state جاوااسکریپت.
- **لولا مشترک**: `origin-bottom-right` تا از یک نقطهٔ دست‌گرفته بچرخند.
- **بلند شدن کارت**: یک چاپ روی هاور خودش به ۱٫۱ اسکل می‌شود و بالای بقیه می‌آید.
- **فقط اشاره‌گر دقیق**: روی لمس بادبزن خاموش می‌ماند. حرکت کمتر پشته را ثابت نگه می‌دارد.

## نحوه استفاده

روی کارت هاور کنید. `fanCards` را با شات‌های خود عوض کنید. پشته است، نه کاروسل.

```tsx
import PolaroidStack from "@/components/polaroid-stack";

export default function Example() {
  return <PolaroidStack />;
}
```

## سفارشی‌سازی

- **تعداد**: آیتم‌های `fanCards` را کم یا زیاد کنید. چرخش‌های `hoverClassName` را یکنواخت پخش کنید.
- **اندازه**: `h-[226px] w-[152px]` روی `cardClassName`.
- **زاویهٔ بادبزن**: مقادیر `rotate(...)`. کارت وسط را روی `0deg` نگه دارید.
- **سرعت**: `duration-200`. زیر یا برابر ۳۰۰ms بماند.
- **عکس‌ها**: `src` و `alt` هر کارت.
- **حاشیه**: `border-[5px]` و `border-b-[40px]` برای پای پولاروید.
- **اسکل**: `hover:[scale:1.1]`.

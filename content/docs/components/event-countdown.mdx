## نحوه استفاده

```tsx
import EventCountdown from "@/components/event-countdown";

export default function Example() {
  return (
    <EventCountdown
      title="تا شروع امتحان"
      subtitle="۱۵ اردیبهشت · ساعت ۰۹:۰۰"
      target="2026-05-05T09:00:00"
    />
  );
}
```

## قابلیت‌ها

- روز، ساعت، دقیقه و ثانیه با عدد فارسی.
- با هر ثانیه، عددها نرم عوض می‌شوند.
- عنوان و تاریخ کنار هم در یک ردیف.
- وقتی زمان تمام شد، پیام «شروع شد» می‌آید.
- در حالت لایت و دارک درست دیده می‌شود.
- حرکت کمتر: بدون انیمیشن اضافه.
- به `motion` نیاز دارد.

## پراپ‌ها

| پراپ | توضیح |
| --- | --- |
| `target` | تاریخ/زمان هدف (`Date`، timestamp یا ISO) |
| `title` | عنوان رویداد |
| `subtitle` | تاریخ نمایشی روبه‌روی عنوان |

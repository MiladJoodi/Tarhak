## نحوه استفاده

```tsx
import PerspectiveTextScroll from "@/components/perspective-text-scroll";

export default function Example() {
  return <PerspectiveTextScroll />;
}
```

## قابلیت‌ها

- سه‌بعدی وابسته به اسکرول: `rotateX`، `translateY` و `translateZ` از منحنی پیشرفت پیروی می‌کنند، نه لوپ کی‌فریم CSS.
- دنبال‌کردن نرم: پیشرفت با lerp نرم می‌شود تا روی ترک‌پد نپرد.
- ورود و خروج: کپی از پایین محو می‌شود، وسط خوانا می‌ماند، بعد عقب می‌رود.
- آگاه از والد اسکرول: داخل اسکرولر تو‌در‌تو هم کار می‌کند، نه فقط پنجره.
- تایپ ادیتوریال: یک بلوک متن سیستم طراحی — بدون کارت و بدون کروم.

```tsx
  return <ThemeToggle />;
}
```

## قابلیت‌ها

- دستگیرهٔ نقطه‌دار: دوازده فرورفتگی روی دکمهٔ برجسته، مثل سوئیچ سخت‌افزاری.
- شیار فرورفته: چاه داخل قرص کنده شده تا دکمه عمق واقعی داشته باشد.
- اول حرکت، بعد رنگ: اول دکمه جابه‌جا می‌شود، بعد شیار پر می‌شود.
- ظاهر روشن و تاریک: خاموش خاکستری روشن است؛ روشن تخته‌سنگی با چاه آبی.
- حرکت کمتر: اسلاید کوتاه‌تر می‌شود؛ وضعیت همچنان عوض می‌شود.

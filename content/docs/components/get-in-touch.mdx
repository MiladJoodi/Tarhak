## نحوه استفاده

```tsx
import GetInTouch from "@/components/get-in-touch";

export default function Example() {
  return <GetInTouch />;
}
```

## قابلیت‌ها

- دکمهٔ براق: گرادیان تیره، هایلایت داخلی و مقیاس فشار روی پوستهٔ CTA.
- هاور دو ضربه‌ای: پرتره و «شما» می‌آیند، یکی می‌شوند، بعد برچسب جدید ظاهر می‌شود.
- فوکوس هم: فوکوس صفحه‌کلید همان توالی هاور را اجرا می‌کند.
- متن سفارشی: `defaultText`، `hoverText`، `youLabel` و `imageSrc` را پاس بدهید.
- حرکت کمتر: توالی به حالت پایانی می‌پرد. لینک همچنان کار می‌کند.

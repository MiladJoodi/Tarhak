## نحوه استفاده

```tsx
import AccessibleAction from "@/components/accessible-action";

export default function Example() {
  return <AccessibleAction />;
}
```

## قابلیت‌ها

- کشیدن به پشت: عکس جلو را کنار بکشید تا پشت پشته برود.
- شیب سه‌بعدی: کارت با اشاره‌گر کج می‌شود تا پشته فیزیکی حس شود، نه تخت.
- کلیک برای چرخش: ضربه روی کارت جلو می‌تواند بدون کشیدن کامل آن را به پشت بفرستد.
- چرخش تصادفی: هر کارت با زاویهٔ جزئی قطعی می‌نشیند تا پشته زنده به‌نظر برسد.
- نشستن فنری: بعد از پرتاب، کارت‌ها در عمق جا می‌گیرند نه اینکه بپرند.

## قابلیت‌ها

- **ریل چیپ**: برچسب‌هایی مثل تأمین پایدار و آمادهٔ ابر به‌صورت قرص شناور.
- **تصویر همگام**: کارت عکس بزرگ با چیپ انتخاب‌شده عوض می‌شود.
- **اسکرول به دید**: چیپ فعال در ریل می‌ماند تا گم نشود.
- **پخش خودکار، بعد مکث**: خودش می‌چرخد و با هاور می‌ایستد.
- **آیکون + یک خط**: هر قابلیت یک نماد و توضیح کوتاه زیر عکس دارد.

## نحوه استفاده

آرایهٔ `FEATURES` را با برچسب، آیکون، تصویر و یک جمله پر کنید. به چیدمان تقریباً دوستونه (چیپ + عکس) نیاز دارد. پخش خودکار برای صفحهٔ اصلی خوب است؛ در قیمت‌گذاری که مقایسه می‌کنند مکث دهید. هشت آیتم کافی است — بیشتر ریل را طولانی می‌کند.

```tsx
import FeatureCarousel from "@/components/feature-carousel";

export default function Page() {
  return <FeatureCarousel />;
}
```

## کجا استفاده شود

- تور قابلیت‌های بازاریابی محصول
- صفحات داستان برند
- سایت‌های غذا، سفر یا سبک زندگی
- بخش‌های «پلتفرم» در SaaS
- هایلایت کنفرانس یا فستیوال

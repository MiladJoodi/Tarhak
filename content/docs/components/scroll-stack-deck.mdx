## قابلیت‌ها

- **ویوپورت چسبان**: مسیر `۵ × ۱۱۰vh` یک صحنهٔ تمام‌صفحه را پین می‌کند تا پشته موقع اسکرول در دید بماند.
- **اسکرول = اسکرابر**: `useScroll` پیشرفت را به `y` و `scale` هر کارت می‌بندد — کار بعدی بالا می‌آید، قبلی عقب می‌رود.
- **پیشرفت فنری**: فنر ملایم روی `scrollYProgress` پشته را از پرش چرخ ماوس دور می‌کند.
- **کارت پوشه‌ای**: تب‌های شماره‌دار روی بدنهٔ رنگی با متن و تصویر ثابت.
- **Lenis روی پنجره**: چرخ نرم اختیاری برای لندینگ واقعی. داخل overflow تو در تو `container` و `enableLenis={false}` بدهید.
- **پیش‌فرض لندینگ**: عنوان، زیرعنوان، راهنمای اسکرول و فوتر — با رشتهٔ خالی / `showFooter={false}` پنهان کنید.

## نحوه استفاده

صفحهٔ بلند لازم است. در بخش کوتاه نگذارید — چیزی برای اسکرول نمی‌ماند. `DEFAULT_PROJECTS` را با کار خودتان عوض کنید. تصاویر عریض باشند. برای صفحهٔ کیس‌استادی یا استودیو مناسب است، نه داشبورد.

```tsx
import ScrollStackDeck from "@/components/scroll-stack-deck";

export default function Example() {
  return <ScrollStackDeck />;
}
```

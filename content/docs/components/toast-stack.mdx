## نحوه استفاده

```tsx
import ToastStack from "@/components/toast-stack";

export default function Example() {
  return <ToastStack />;
}
```

## قابلیت‌ها

- سه نوع اعلان: موفقیت (سبز)، خطا (قرمز)، هشدار (نارنجی).
- ورود از بالا با فنر و بلور کوتاه؛ خروج نرم با جمع شدن پشته.
- نوار پیشرفت و بستن دستی؛ حداکثر چهار اعلان هم‌زمان.
- آیکون Hugeicons، RTL، فونت Estedad و کپی فارسی.
- به `motion` و Hugeicons نیاز دارد.

## قابلیت‌ها

- **سه چیدمان**: فهرست، گرید کارت و پشتهٔ «بسته» — همان آیتم‌ها، وضعیت متفاوت.
- **مورف shared-element**: عنوان‌ها، تصاویر و شناسه‌ها به‌جای چشمک‌زدن به جای جدید می‌لغزند.
- **سوییچ قطعه‌ای**: سوئیچ کوچک قرصی در بالا تغییر حالت را مثل دوربین حس می‌کند، نه ریلود.
- **سلول‌های اثر**: هر قطعه عکس، دسته و شمارهٔ کاتالوگ دارد.
- **فنرهای سریع**: تغییر چیدمان زود می‌نشیند تا مرور کند حس نشود.

## نحوه استفاده

جایی بگذارید که کسی مجموعه‌ای از چیزهای خودش یا کیوریت‌شده را ورق می‌زند. چند آیتم با تصویر و عنوان لازم است؛ سوییچ داخلش است. ستون با عرض متوسط بدهید — خیلی باریک پشته شلوغ می‌شود، خیلی عریض فهرست گم می‌شود.

```tsx
import AnimatedCollection from "@/components/animated-collection";

export default function Example() {
  return <AnimatedCollection />;
}
```

## کجا استفاده شود

- صفحات «مجموعهٔ من» کلکسیونر یا گالری
- کتابخانه‌های موسیقی، بلیت یا مرچ
- گالری‌های سیستم طراحی برای توکن یا شات
- نمای آیتم‌های ذخیره‌شدهٔ مارکت‌پلیس
- ایندکس پورتفولیو با سوییچ نما

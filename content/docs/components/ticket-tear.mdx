## نحوه استفاده

```tsx
  return <TicketTear />;
}
```

## قابلیت‌ها

- پرفراژ زنده: نقطه‌ها با کشیدن یکی‌یکی جمع می‌شوند تا حس پارگی واقعی بدهد.
- کشش و کج شدن: نیمهٔ پایین موقع درگ کمی می‌چرخد و کج می‌شود؛ بدنهٔ اصلی کمی بالا می‌آید.
- سقوط: بعد از آستانه، نیمه با چرخش و انحراف می‌افتد، الیاف پاره و غبار کاغذ دیده می‌شود، بعد ریست.
- دکمهٔ «جدا کردن از پرفراژ» برای دسترسی بدون درگ؛ وضعیت با `aria-live` اعلام می‌شود.
- جزئیات بلیط: نوار جوهر، فویل طلایی، مهر ورود، بارکد و QR کوچک.
- `prefers-reduced-motion`: بدون درگ طولانی؛ جدا شدن و ریست کوتاه‌تر.
- به `motion` نیاز دارد.

## نحوه استفاده

```tsx
import TicketTear from "@/components/ticket-tear";

export default function Example() {
  return <TicketTear />;
}
```

## قابلیت‌ها

- بلیط افقی واقعی با پرفراژ، بریدگی کناری، بارکد و جزئیات رویداد.
- درگ عمودی نیمهٔ پایین تا آستانهٔ جدا شدن؛ اگر کافی نباشد فنری برمی‌گردد.
- بعد از جدا شدن، نیمه می‌افتد و محو می‌شود؛ چند ثانیه بعد ریست.
- دکمهٔ «جدا کردن از پرفراژ» برای دسترسی بدون درگ.
- روی دسکتاپ کمی بزرگ‌تر؛ موبایل جمع‌وجور می‌ماند.
- حرکت کمتر: بدون درگ طولانی؛ جدا شدن و ریست کوتاه‌تر.
- به `motion` نیاز دارد.

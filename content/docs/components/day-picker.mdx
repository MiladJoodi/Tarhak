## قابلیت‌ها

- **تکرار اول**: روزانه، هفتگی، ماهانه، سالانه در قرص مورف‌شونده.
- **چیپ روز**: وقتی هفتگی روشن است، ی–ش ظاهر می‌شوند تا چند روز را بزنید.
- **تعویض بلور**: باز شدن ردیف گزینه برچسب «تکرار» را بلور می‌کند تا تمرکز روی انتخاب بماند.
- **ریسایز فنری**: کارت با محتوا رشد و جمع می‌شود — بدون جعبهٔ خالی اضافه.
- **خلاصه وقتی بسته**: جمع کنید و هنوز انتخاب‌تان را می‌بینید.

## نحوه استفاده

برای زمان‌بندی، یادآور و دورهٔ صورتحساب است — نه تقویم کامل. در فرم یا شیت تنظیمات بگذارید. معمولاً آرایهٔ `options` را عوض می‌کنید. ستون جمع‌وجور (~۳۲۰px) بدهید؛ از قبل شبیه کنترل بومی است.

```tsx
import DayPicker from "@/components/day-picker";

export default function Page() {
  return <DayPicker />;
}
```

## کجا استفاده شود

- تنظیمات کار تکراری یا یادآور
- انتخاب دورهٔ صورتحساب
- آنبوردینگ اپ تقویم
- تکرار خبرنامه یا دایجست
- جریان رزرو که «کدام روزها» لازم دارد

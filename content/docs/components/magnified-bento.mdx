## قابلیت‌ها

- **ردیف‌های مارکی**: سه خط چیپ در جهت مخالف حرکت می‌کنند — کشف نیاز، انتشار، امنیت و بقیه.
- **لنز قابل‌کشیدن**: شیشهٔ دایره‌ای اشاره‌گر را دنبال می‌کند و چیپ‌های زیر را بزرگ می‌کند.
- **لایهٔ دوگانه**: متن بزرگ‌شده با همان چیپ‌ها قفل است تا از هم‌ترازی خارج نشود.
- **قاب کارت**: عنوان و یک خط کوتاه زیر پنجره می‌نشیند — «گردش‌کارهای هوشمند».
- **درخشش لنز**: هایلایت روی شیشه تا مثل ذره‌بین واقعی خوانده شود.

## نحوه استفاده

این یک تصویر قابلیت است، نه UI جستجو. `TAG_ROWS` و عنوان/توضیح در `CONFIG` را ویرایش کنید. به درگ اشاره‌گر (یا هاور) و یک چاه هم‌اندازهٔ کارت نیاز دارد. روی آن لایهٔ تعاملی دیگر نگذارید.

```tsx
import MagnifiedBento from "@/components/magnified-bento";

export default function Page() {
  return (
    <div className="h-screen flex items-center justify-center">
      <MagnifiedBento />
    </div>
  );
}
```

## کجا استفاده شود

- کاشی‌های توانمندی آژانس یا استودیو
- گرید بنتو «گردش‌کار» در SaaS
- بازاریابی مهارت یا خدمات
- صفحات محصول دربارهٔ جستجو یا برچسب‌گذاری
- ردیف‌های قابلیت در لندینگ

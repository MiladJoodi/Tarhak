## قابلیت‌ها

- **هایلایت هاور**: پس‌زمینهٔ نرم بین آیتم‌ها جابه‌جا می‌شود.
- **زیرمنوی فنری**: باز و بسته شدن دسته‌ها با اسپرینگ نرم.
- **جمع‌شدن به آیکون**: حالت `collapsible="icon"` با تولتیپ.
- **راست‌چین**: پیش‌فرض `dir="rtl"` و `side="right"`.

الهام از [Animate UI Sidebar](https://animate-ui.com/docs/components/radix/sidebar) (بر پایهٔ shadcn/ui).

## نحوه استفاده

```tsx
import AnimateSidebar from "@/components/animate-sidebar";

export default function Page() {
  return (
    <div className="h-svh w-full overflow-hidden">
      <AnimateSidebar />
    </div>
  );
}
```

برای ساخت سفارشی، exportهای نام‌دار (`SidebarProvider`, `Sidebar`, `SidebarMenuButton`, …) را هم دارید.

## Props اصلی

| Prop | توضیح |
| --- | --- |
| `className` | کلاس ظرف ریشه |
| `position` | `absolute` (داخل قاب) یا `fixed` (صفحهٔ کامل) |
| `disableMobile` | سایدبار را داخل قاب نگه می‌دارد (بدون Sheet). پیش‌فرض: `true` وقتی `position="absolute"` |

برای اپ تمام‌صفحه با Sheet موبایل واقعی:

```tsx
<AnimateSidebar position="fixed" disableMobile={false} />
```

---
title: Smooth Dropdown
description: A round button that morphs into a menu — rows stagger in, the shell resizes, and it closes on outside click.
---

## قابلیت‌ها

- **تغییر شکل**: دکمه بدون لایهٔ پاپ‌آپ جدا، خودش به منو تبدیل می‌شود.
- **ورود پلکانی**: پروفایل، ارتقا حساب و بقیه به‌ترتیب ظاهر می‌شوند.
- **فعال و هاور**: ردیف فعلی مشخص است؛ هاور با آن تداخل ندارد.
- **کلیک بیرون**: با کلیک بیرون از منو، جمع می‌شود.
- **فنر، نه محو شدن**: ارتفاع و آیتم‌ها یک حرکت واحد دارند.

## نحوه استفاده

برای منوی حساب یا منوی بیشتر مناسب است. برچسب‌ها و آیکون‌ها را در `menuItems` عوض کنید. به کلیک و کمی فضای زیر دکمه نیاز دارد. داخل والد با `overflow: hidden` نگذارید وگرنه تغییر شکل بریده می‌شود. ردیف‌ها را به مسیر واقعی وصل کنید.

```tsx
import SmoothDropdown from "@/components/smooth-dropdown";

export default function Page() {
  return (
    <div className="flex items-center justify-center h-[400px] w-full">
      <SmoothDropdown />
    </div>
  );
}
```

## کجا استفاده شود

- منوی حساب در هدر
- میانبر ارتقا حساب / صورتحساب
- نوار ابزار فشرده
- منوی بیشتر در موبایل
- نمونهٔ ناوبری بدون کتابخانهٔ کامل dropdown

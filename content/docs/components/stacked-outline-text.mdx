## قابلیت‌ها

- **کشیدن کلمه**: بلوک داخل صحنه دنبال نشانگر می‌آید، با کمی کشسانی در لبه‌ها.
- **رد سرعت**: کشیدن سریع‌تر کپی‌های خط‌دار بیشتری پشت حروف می‌گذارد. آهسته کنید تا جمع شوند.
- **نشست فنری**: پشته با رها کردن روی کلمه برمی‌گردد.
- **جابه‌جایی با کیبورد**: فوکوس کنید و پیکان‌ها را بزنید. هر ضربه یک قدم کوتاه و محدود است.
- **حرکت کمتر**: رد و مقیاس کشیدن خاموش می‌شود. کلمه همچنان جابه‌جا می‌شود.

## نحوه استفاده

روی زمینهٔ تیره بگذارید. با `text` کلمه را عوض کنید. `fontSize` و `stacks` اختیاری‌اند.

```tsx
import StackedOutlineText from "@/components/stacked-outline-text";

export default function Example() {
  return <StackedOutlineText text="طرح" />;
}
```

## کجا استفاده شود

- قطعات پورتفوی موشن یا تایپ
- نشان‌واژهٔ هیرو
- تیزر رویداد یا دراپ
- آغازگرهای تحریریه
- دموهای کشیدن برای بازی

---

## قابلیت‌ها

- **تا شدن سه‌بعدی**: هر پنل روی محور Y از بیرون صفحه می‌چرخد و صاف می‌نشیند.
- **دو سمت**: جزئیات پرداخت از راست. خلاصهٔ سبد از چپ.
- **فیلدهای پشت‌سرهم**: ردیف‌های فرم و خطوط سبد با Motion محو، سر می‌خورند و از بلور درمی‌آیند.
- **اقدامات سبد**: تعداد، کد تخفیف `SAVE10` و مبلغ زنده.
- **حرکت کمتر**: تا شدن و استگر به محو آنی تبدیل می‌شوند. کشوها همچنان باز می‌شوند.

## نحوه استفاده

```tsx
import DrawerButtons from "@/components/drawer-buttons";

export default function Example() {
  return <DrawerButtons />;
}
```

## کجا استفاده شود

- تسویهٔ فروشگاه و پرداخت
- سبد شناور در هدر
- فرم‌های صورتحساب کناری
- پیش‌نمایش سفارش قبل از خرید
- دموهای موشن پنل کناری

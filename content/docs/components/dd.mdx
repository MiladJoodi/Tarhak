## قابلیت‌ها

- **نقل‌قول کلمه‌به‌کلمه**: خط یکجا محو نمی‌شود — هر کلمه بلند می‌شود و تیز می‌گردد.
- **قفل پرتره**: چهرهٔ تمام‌صفحه کنار متن می‌نشیند تا شخص همان محصول باشد.
- **جفت آمار**: دو متریک زیر نقل‌قول (تبدیل، آنبوردینگ، سرعت).
- **ریل بندانگشتی**: پرتره‌ها کنار هم؛ فعال همان داستان جاری است.
- **چرخش خودکار**: چرخهٔ پنج‌ثانیه‌ای با فنر تا ریل نپرد.

## نحوه استفاده

چیدمان عریض تحریریه‌ای می‌خواهد — عکس + نقل‌قول، نه کارت کوچک. آرایهٔ `TESTIMONIALS` را عوض کنید (نام، نقش، نقل‌قول، آمار، عکس). پخش خودکار روشن است؛ اگر صفحه حرکت زیاد دارد خاموشش کنید. مناسب صفحهٔ اصلی یا پایان مطالعهٔ موردی.

```tsx
import Dd from "@/components/dd";

export default function Example() {
  return <Dd />;
}
```

## کجا استفاده شود

- اثبات اجتماعی صفحهٔ اصلی با عکاسی
- پایان مطالعهٔ موردی
- صفحات قیمت که به چهره نیاز دارند، نه دیوار لوگو
- داستان مشتری آژانس
- صفحات لانچ با چند نقل‌قول قوی

## نحوه استفاده

```tsx
import PaperShredButton from "@/components/paper-shred-button";

export default function Example() {
  return <PaperShredButton />;
}
```

## قابلیت‌ها

- پیش‌نمایش با هاور یا فوکوس: دکمه بلند می‌شود، آیکون سطل کج می‌شود و صفحهٔ سفید بالا می‌آید.
- خرد کردن با کلیک: صفحه از پایین بریده می‌شود. نوارهای SVG زیر آن کشیده می‌شوند.
- غیرفعال هنگام خرد کردن: دکمه در حالت‌های `shredding` و `shredded` خاموش می‌ماند.
- ریست خودکار: بعد از نشستن نوارها به idle برمی‌گردد تا دوباره بزنید.
- حرکت کمتر: انتقال‌های نزدیک به آنی، بدون کشیدن طولانی مسیر، تأخیر کوتاه خرد کردن.
- به `motion` نیاز دارد. این دموی بصری است، نه حذف واقعی.

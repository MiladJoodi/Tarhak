## قابلیت‌ها

- **چیپ‌های در حال سقوط**: هر کارت داخل سطل می‌افتد، بعد بعدی در حلقه می‌آید.
- **کاسهٔ SVG لایه‌ای**: قیف شکل واقعی با بلور و عمق است — نه مستطیل گرد.
- **آیکون + کپی**: آمادهٔ تولید، حرکت روان، دسترس‌پذیر، طراحی مدرن — کوتاه و خوانا داخل چیپ.
- **چرخهٔ پیوسته**: هر دو ثانیه چیپ جلو عوض می‌شود تا سطل هرگز ساکن نماند.
- **بدون موتور سه‌بعدی**: Motion و SVG پرتاب را بدون WebGL می‌دهند.

## نحوه استفاده

به‌عنوان توضیح‌دهندهٔ قابلیت استفاده کنید، نه فرم. `INITIAL_CHIPS` را با عنوان، خط و آیکون خودتان عوض کنید. صحنهٔ عریض و کوتاه بدهید (افقی می‌خواهد). پخش خودکار اصل ماجراست — کنار چیزی که خودش هم حلقه می‌زند نگذارید.

```tsx
import Bucket from "@/components/bucket";

export default function Page() {
  return (
    <div className="h-screen flex items-center justify-center">
      <Bucket />
    </div>
  );
}
```

- لحظه‌های «چه به‌دست می‌آورید» صفحهٔ اصلی

- بازاریابی ابزار توسعه‌دهنده (تایپ‌سیف، سریع، دسترس‌پذیر)
- حلقه‌های غرفهٔ کنفرانس
- بخش‌های دربارهٔ محصول بالای فولد

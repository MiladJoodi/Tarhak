## قابلیت‌ها

- **یکی باز، بقیه جا می‌دهند**: ارتفاعات، سرخ‌فام، ژرفا — یکی را بزن و مالک ردیف می‌شود.
- **جابه‌جایی ردیف**: همسایه‌ها به ردیف بعد می‌روند، نه روی هم.
- **شستشوی رنگ**: هر سلول رنگ تأکیدی دارد که با عکس نرم می‌آید.
- **روکش عنوان**: نام و زیرعنوان روی عکس بازشده می‌نشینند.
- **انیمیشن لایه‌بندی**: سلول‌ها با layout موشن تغییر شکل می‌دهند، نه ریفلو سخت.

## نحوه استفاده

با مجموعهٔ کوچک عکس (سه یا چهار) کار می‌کند. کلیک برای باز کردن؛ کلیک روی آیتمی که تنهاست کاری نمی‌کند — عمدی است. فضای تمام‌عرض بدهید. `ITEMS` را با عنوان، زیرعنوان و عکس خودتان عوض کنید.

```tsx
import FluidExpandingGrid from "@/components/fluid-expanding-grid";

export default function Page() {
  return <FluidExpandingGrid />;
}
```

## کجا استفاده شود

- گالری سفر یا منظره
- جستارهای عکاسی تحریریه
- صفحات خانوادهٔ محصول
- شبکهٔ پروژهٔ معماری
- بخش‌های مودبورد بازاریابی

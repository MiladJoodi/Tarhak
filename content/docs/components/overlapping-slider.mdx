## قابلیت‌ها

- **عرض لندینگ**: کارت‌ها ۳۴۰×۴۶۰ هستند و لبه‌به‌لبه می‌روند. در دسکتاپ معمولی چهارتا جا می‌شود؛ بعدی سرک می‌کشد.
- **ثابت تا حرکت**: در حالت سکون شیب نیست. بکشید، روی کارت بزنید، یا از پیکان‌ها استفاده کنید.
- **عقب‌رفتن کارت قبلی**: کارتی که ترک می‌کنید کوچک و عقب می‌شود. بقیه سر جایشان می‌مانند.
- **پیکان‌ها در ابتدا**: یک‌به‌یک قدم بزنید. نقاط پیش‌فرض خاموش‌اند؛ با `showDots` روشن کنید.
- **هر کارتی**: `children` بدهید، یا `items` به‌همراه `renderItem`.

## نحوه استفاده

عرض کامل صفحه را بدهید. در ستون باریک نگذارید.

```tsx
import OverlappingSlider from "@/components/overlapping-slider";

export default function Page() {
  return <OverlappingSlider />;
}
```

برای کنترل با داده:

```tsx
import { OverlappingSlider, ProfileCard } from "@/components/overlapping-slider";

<OverlappingSlider
  items={profiles}
  renderItem={(card) => <ProfileCard card={card} />}
  cardWidth={340}
  cardHeight={460}
/>
```

## قابلیت‌ها

- **کارت گام‌به‌گام**: عنوان و توضیح در هر گام عوض می‌شود؛ ادامه / بازگشت در فوتر است.
- **ارتفاع اندازه‌گیری‌شده**: کارت با فیلدها رشد می‌کند تا برش ناگهانی نباشد.
- **اسلاید وابسته به جهت**: جلو و عقب خلاف هم انیمیت می‌شوند.
- **پشتهٔ فرم واقعی**: React Hook Form + Zod، تقویم شمسی (جلالی)، برچسب، حال‌وهوا و toast در پایان.
- **پیشرفت در قاب**: همیشه می‌دانید در کدام گام هستید.

## نحوه استفاده

این یک ویزارد کامل است، نه یک ورودی تکی. `stepTitles` و سوئیچ `content` را با فیلدهای خود عوض کنید. یک ستون متوسط (`max-w-xl`) بدهید. اعتبارسنجی از قبل وصل است — به‌جای toast دمو، ارسال را به API وصل کنید.

```tsx
import MultiStepForm from "@/components/multi-step-form";

export default function Page() {
  return (
    <div className="max-w-xl mx-auto py-12">
      <MultiStepForm />
    </div>
  );
}
```

## کجا استفاده شود

- جریان ایجاد پروژه
- پرسشنامهٔ آنبوردینگ
- فرم درخواست قیمت
- ویزارد استخدام یا درخواست
- تنظیماتی که برای یک صفحه خیلی بلندند

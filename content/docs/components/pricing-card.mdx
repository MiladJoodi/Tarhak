## قابلیت‌ها

- **سوییچ دوره**: ماهانه و سالانه یک هایلایت کشویی مشترک دارند.
- **اعداد غلتان**: قیمت‌ها با NumberFlow تیک می‌خورند، نه پرش ناگهانی.
- **انتخاب پلن**: پلاس / استاندارد و بقیه با حاشیه و تیک انتخاب می‌شوند.
- **لیست قابلیت**: بولت‌های کوتاه زیر هر پلن — فضا، بازیابی، رمزنگاری.
- **برچسب تخفیف**: یک دوره می‌تواند بج بپوشد بدون چیدمان اضافه.

## نحوه استفاده

آرایهٔ `plans` را برای نام، قیمت و بولت‌ها ویرایش کنید. ستون را حدود ۳۲۰–۳۸۴px نگه دارید — کارت است، نه جدول کامل قیمت. CTA را به تسویه وصل کنید. سالانه باید واحد ارزان‌تر باشد تا سوییچ صادق به نظر برسد.

```tsx
import PricingCard from "@/components/pricing-card";

export default function Page() {
  return (
    <div className="flex items-center justify-center py-10 w-full">
      <PricingCard />
    </div>
  );
}
```

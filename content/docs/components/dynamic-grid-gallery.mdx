## قابلیت‌ها

- **بزرگ‌شدن با هاور**: ردیف و ستون فعال `expandFactor` (پیش‌فرض ۱٫۹۵) می‌گیرند؛ بقیه عقب می‌نشینند.
- **شش قاب**: صفحهٔ ۳×۲. با `items` عکس‌های خودتان را بگذارید.
- **آسان نرم**: مسیرهای گرید با منحنی مکعبی عوض می‌شوند تا رشد ناگهانی نباشد.
- **وینیت**: کاشی‌های بیکار کمی تیره می‌مانند؛ هاور‌شده روشن می‌شود.

## نحوه استفاده

```tsx
import DynamicGridGallery from "@/components/dynamic-grid-gallery";

export default function Example() {
  return <DynamicGridGallery />;
}
```

## کجا استفاده شود

- گالری نمونهٔ کار استودیو
- صفحهٔ داستان سفر یا طبیعت
- ویترین محصول بصری
- لندینگ عکاسی
- نمونه‌های موشن گرید تعاملی

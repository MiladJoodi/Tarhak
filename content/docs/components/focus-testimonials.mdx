## قابلیت‌ها

- **تمرکز با هاور**: بقیه کم‌رنگ، یک صدا جلو.
- **تولتیپ نویسنده**: نام، نقش و شرکت نزدیک اشاره‌گر شناور می‌مانند.
- **باز کردن بیشتر**: کنترلی نقل‌قول‌های اضافه را نشان می‌دهد.
- **خوانایی نقل**: خط متن قهرمان است؛ آواتارها فهرست‌اند.
- **کلیک لازم نیست**: روی دسکتاپ هاور کار می‌کند؛ باز شدن نام‌های بیشتر را پوشش می‌دهد.

## نحوه استفاده

به مجموعه‌ای از نقل‌قول با آواتار، نام و شرکت نیاز دارید. هاور تعامل اصلی است؛ برای صفحات بازاریابی دسکتاپ مناسب‌تر است. `INITIAL_TESTIMONIALS` و فهرست‌های اضافه را عوض کنید. در ستون کوچک نگذارید — ردیف چهره‌ها فضا می‌خواهد.

```tsx
import FocusTestimonials from "@/components/focus-testimonials";

export default function Example() {
  return <FocusTestimonials />;
}
```

## کجا استفاده شود

- اثبات اجتماعی صفحهٔ اصلی
- زیر پلن‌ها در قیمت‌گذاری
- پایان مطالعهٔ موردی
- دیوار مشتریان آژانس
- صفحات لانچ با چند نقل قوی

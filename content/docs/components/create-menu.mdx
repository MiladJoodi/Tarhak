## قابلیت‌ها

- **مورف جزیره**: قرص از یک دکمه به منوی پشته‌ای با فنر رشد می‌کند.
- **اکشن‌های ساخت**: پست، ایده، رشته، قالب، بازنویسی و ابزار هوش مصنوعی در یک جا.
- **کلیک بیرون**: با کلیک بیرون منو به دکمه جمع می‌شود.
- **دمو شبیه سایدبار**: در کروم ساختگی اپ نشان داده می‌شود تا جای زندگی‌اش معلوم باشد.

## نحوه استفاده

نزدیک بالای سایدبار یا کروم ادیتور نگه دارید. آرایهٔ آیتم‌ها را برای انواع ساخت خودتان ویرایش کنید. به والد `overflow-visible` بدهید تا منوی بازشده بریده نشود.

```tsx
import CreateMenu from "@/components/create-menu";

export default function Page() {
  return <CreateMenu />;
}
```

## کجا استفاده شود

- سایدبار نوشتن یا CMS
- ابزار زمان‌بندی شبکهٔ اجتماعی
- استودیو محتوای هوش مصنوعی
- منوهای «جدید» پروژه
- حالت خالی داشبورد که با ساخت شروع می‌شود

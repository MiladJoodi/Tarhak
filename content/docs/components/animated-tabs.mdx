## نحوه استفاده

```tsx
import AnimatedTabs from "@/components/animated-tabs";

export default function Example() {
  return <AnimatedTabs />;
}
```

## قابلیت‌ها

- نشانگر قرصی با فنر سنگین بین تب‌ها می‌لغزد.
- محتوا با جابه‌جایی، بلور و اسکیل عوض می‌شود.
- عنوان، متن و کارت‌های آمار یکی‌یکی ظاهر می‌شوند.
- جهت حرکت با ترتیب تب‌ها هماهنگ است.
- پشتیبانی لایت و دارک.
- حرکت کمتر: بدون جابه‌جایی و بلور.
- به `motion` نیاز دارد.

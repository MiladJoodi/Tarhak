## نحوه استفاده

```tsx
import AnimatedTabs from "@/components/animated-tabs";

export default function Example() {
  return <AnimatedTabs />;
}
```

## قابلیت‌ها

- سطح `bg-card` با شعاع ۲۰ و `border-border` — بدون سایهٔ سنگین.
- نشانگر تب با `layoutId` روی `bg-accent` و `rounded-2xl`.
- متن با Estedad، `text-foreground` / `text-muted-foreground`.
- کارت‌های آمار هم‌سبک ردیف‌های فیلتر.
- جهت حرکت با ترتیب تب‌ها هماهنگ است.
- `prefers-reduced-motion` پشتیبانی می‌شود.
- به `motion` و `clsx` نیاز دارد.

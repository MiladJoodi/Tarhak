## نحوه استفاده

```tsx
import ScanDocument from "@/components/scan-document";

export default function Example() {
  return <ScanDocument />;
}
```

## قابلیت‌ها

- باز شدن از دکمه: صفحه از پایین رشد می‌کند و می‌نشیند.
- چرخش فیزیکی: یک دور کامل `rotateY` با عطف، خطوط جلو و پشت خاکستری.
- نور اسکن: نوار نارنجی پایین می‌رود، مکث می‌کند و برمی‌گردد. دو نسخه در چرخش دیده می‌شوند.
- متن وضعیت: اسکن ← در حال اسکن ← انجام شد. برچسب منبع حقیقت است، نه موشن.
- ریست خودکار: بعد از انجام‌شدن به اسکن برمی‌گردد تا دوباره بزنید.
- حرکت کمتر: بدون چرخهٔ سه‌بعدی. محو کوتاه، بعد انجام‌شدن، بعد ریست.

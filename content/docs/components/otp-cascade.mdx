## نحوه استفاده

```tsx
import OtpCascade from "@/components/otp-cascade";

export default function Example() {
  return <OtpCascade />;
}
```

## قابلیت‌ها

- شش خانهٔ ورودی با فوکوس خودکار و جابه‌جایی با کلیدها.
- پشتیبانی از رقم‌های لاتین، فارسی و عربی.
- چسباندن (paste) کل کد یکجا.
- خط عمودی چشمک‌زن در خانهٔ فعال.
- بازخورد یکسان برای درست/غلط: دایرهٔ رنگی با تیک یا ضربدر؛ فقط رنگ فرق می‌کند.
- لرزش ملایم و تغییر رنگ خانه‌ها هنگام خطا.
- حرکت کمتر: بدون انیمیشن‌های اضافه.
- به `motion` نیاز دارد.

## قابلیت‌ها

- **زبانهٔ واقعی**: بدنهٔ پوشه با گرادیان کاغذ، بافت و لبهٔ داخلی؛ نه یک مستطیل تخت.
- **بلند شدن با هاور**: پوشه پایین می‌آید، عکس زوم می‌شود، شیء (پالت، دوربین، گیاه) بالا شناور می‌ماند.
- **پالت کرافت**: رنگ‌های کاغذی گرم که روی لایت و دارک خوانا می‌مانند.
- **لمس و کیبورد**: روی موبایل با لمس باز/بسته؛ Enter و Space هم کار می‌کند.
- **لینک اختیاری**: اگر `href` بدهید، کل کارت یک `<a>` می‌شود.
- **`prefers-reduced-motion`**: شناور شدن حلقه‌ای خاموش می‌شود؛ جابه‌جایی کوتاه می‌ماند.

## نحوه استفاده

```tsx
import CardFolder, { FolderPeek } from "@/components/card-folder";

export default function Example() {

}
```

با دادهٔ سفارشی:

```tsx

```

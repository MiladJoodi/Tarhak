## قابلیت‌ها

- **زبانهٔ پوشه**: کارت‌های شماره‌دار ۰۱، ۰۲، ۰۳ مثل پرونده می‌نشینند، نه کاشی معمولی.
- **بلند شدن با هاور**: پوشه جلو می‌آید؛ یک شیء سه‌بعدی (پالت، دوربین، گیاه) بالای آن شناور می‌شود.
- **نگاه به عکس**: پس‌زمینه از بدنهٔ پوشه دیده می‌شود تا هر کارت صحنه داشته باشد.
- **کاغذ رنگی**: پرکننده‌های یاسی، هلویی و نعنایی نرم با رنگ تایپ هماهنگ.
- **لینک اختیاری**: اگر `href` بدهید، کل کارت یک `<a>` می‌شود.

## نحوه استفاده

تصاویر، رنگ‌ها، محتوا و تنظیمات انیمیشن را از props کارت عوض کنید.

```tsx
import CardFolder from "@/components/card-folder";

export default function Example() {
  return <CardFolder />;
}
```

## کجا استفاده شود

- گالری نمونه‌کار و پورتفolio
- کارت‌های مجموعه در داشبورد طراحی
- معرفی دستهٔ محصولات
- صفحهٔ «پوشه‌های پروژه»
- تیزر کمپین با صحنهٔ بصری

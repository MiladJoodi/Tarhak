## نحوه استفاده

```tsx
import FilterInteraction from "@/components/filter-interaction";

export default function Example() {
  return <FilterInteraction />;
}
```

## قابلیت‌ها

- دو دایرهٔ کنار هم: نماد فیلتر کنار نوع انتخاب‌شده (وظایف، رویدادها، یادآورها…).
- پنل تغییرشکل: دکمهٔ فیلتر با `layoutId` مشترک به فهرست تبدیل می‌شود.
- ردیف‌های پله‌ای: گزینه‌ها یکی‌یکی می‌آیند، نه همه با هم.
- تیک روی انتخاب: ردیف فعال تیک پر می‌گیرد.
- آیکون به‌عنوان خلاصه: وقتی فهرست بسته شد، دایرهٔ کناری هنوز انتخاب را نشان می‌دهد.

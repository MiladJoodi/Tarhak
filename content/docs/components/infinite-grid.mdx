## قابلیت‌ها

- **بوم کاشی‌شدهٔ بی‌پایان**: یک پوشش ۳×۳ تا شبکه تمام نشود.
- **کشیدن برای حرکت**: درگ اشاره‌گر با اینرسی و کمی ادامه بعد از رها کردن.
- **چرخ و ترک‌پد**: اسکرول دوحوره با همان دنبال‌کردن نرم.
- **کجی سرعت**: سلول‌ها کمی با سرعت حرکت کج می‌شوند تا حس فیزیکی بدهد.
- **تصویر + عنوان**: عکس محصول با عنوان و قیمت — بدون قاب کارت.
- **لکه‌های محیطی**: رنگ نرم اختیاری پشت شبکه.

## نحوه استفاده

به ویوپورت کامل نیاز دارد. لیستی از محصولات با عکس، عنوان و قیمت بدهید. درگ و ترک‌پد هر دو حرکت می‌دهند؛ مثل کف فروشگاه است نه گرید CSS. در بخش کوتاه نگذارید — جا برای گشتن لازم است.

```tsx
import InfiniteGrid from "@/components/infinite-grid";

export default function Example() {
  return <InfiniteGrid />;
}
```

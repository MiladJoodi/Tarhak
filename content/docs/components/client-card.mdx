---

## قابلیت‌ها

- **چیدمان مشترک**: ریل آواتار با `layoutId` به شبکهٔ کامل چهره‌ها باز می‌شود.
- **حلقهٔ پرداخت**: پیشرفت دایره‌ای از مبلغ پرداخت‌شده در برابر کل.
- **حلقهٔ مهلت**: زمان مصرف‌شده در برابر بازهٔ قرارداد، با برچسب کوتاه «X روز مانده».
- **هویت**: نام، کشور و پرتره روی کارتی جمع‌وجور.

## نحوه استفاده

مقادیر پیش‌فرض را با دادهٔ مشتری عوض کنید. `amountPaid` و `totalAmount` حلقهٔ پرداخت را می‌سازند؛ `startDate` و `deadline` حلقهٔ مهلت را.

```tsx
import ClientCard from "@/components/client-card";

export default function Example() {
  return <ClientCard />;
}
```

## کجا استفاده شود

- داشبورد CRM و حساب‌ها
- لیست مشتریان آژانس
- نمای پروژهٔ فریلنسری
- کارت‌های وضعیت پرداخت
- پنل مدیریت قرارداد

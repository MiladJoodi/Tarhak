## نحوه استفاده

```tsx
import AnalogStick from "@/components/analog-stick";

export default function Example() {
  return <AnalogStick />;
}
```

## قابلیت‌ها

- کلاهک فیزیکی: حلقه‌های لایه‌ای، کاسهٔ داخلی، سایه‌های پشته‌ای، چهار نقطه روی وجه.
- فشار CSS: چهار ناحیهٔ نامرئی با چرخش ۴۵° شیب `:has()` را می‌رانند. بدون state در React.
- نور جهت: فلش متناظر کهربایی پر می‌شود و می‌درخشد.
- فقط اشاره‌گر دقیق: هاور به `(hover: hover) and (pointer: fine)` محدود است.
- حرکت کمتر: کلاهک سر جایش می‌ماند. فلش هنوز می‌تواند رنگ عوض کند.
- به `:has()` نیاز دارد. مرورگرهای قدیمی‌تر اهرم را در حالت سکون نشان می‌دهند.

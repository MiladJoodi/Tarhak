## قابلیت‌ها

- **نشان دنبال‌کنندهٔ ردیف**: کاشی شیدر به عنوان هاور‌شده می‌لغزد.
- **پرشدن مایع**: یک canvas کوچک WebGL رنگ‌های برند را در حرکت مخلوط می‌کند.
- **تعویض آیکون**: یک علامت توپر در کاشی می‌نشیند و با ردیف کراس‌فید می‌شود.
- **متن با هاور**: توضیح برای آیتم فعال ظاهر می‌شود؛ در موبایل با ضربه.

## نحوه استفاده

`ITEMS` را برای عنوان، متن، تصاویر Unsplash، آیکون، seed و رنگ RGB ویرایش کنید. به WebGL2 نیاز دارد. تایپوگرافی از `foreground` / `muted-foreground` می‌آید و با تم هماهنگ است.

```tsx
import LiquidIndex from "@/components/liquid-index";

export default function Page() {
  return <LiquidIndex />;
}
```

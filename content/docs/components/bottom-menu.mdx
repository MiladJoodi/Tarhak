title: Bottom Menu

---

## قابلیت‌ها

- **داک جمع‌شده**: پنج آیکون در یک قرص می‌نشینند تا یکی را انتخاب کنید.
- **سینی‌های بازشونده**: خانه، جستجو، هشدار، پروفایل و تم هر کدام منوی کوچک خودشان را باز می‌کنند.
- **ارتفاع اندازه‌گیری‌شده**: سینی با `useMeasure` رشد می‌کند تا با عوض شدن محتوا نپرد.
- **سوییچ تم**: روشن، تیره و سیستم در آخرین اسلات هستند.
- **کلیک بیرون برای بستن**: با ضربهٔ بیرون داک دوباره جمع می‌شود.

## نحوه استفاده

ته یک لایه‌آوت عرض موبایل یا دموی شناور پارک کنید. آرایه‌های `HOME_ITEMS` / ناو را برای برچسب و آیکون ویرایش می‌کنید. کمی فضای عمودی برای سینی باز لازم است. شِل کامل اپ نیست — به کامپوزر فکر کنید، نه نوار ناوبری.

```tsx
import BottomMenu from "@/components/bottom-menu";

export default function Page() {
  return <BottomMenu />;
}
```

## کجا استفاده شود

- صفحات بازاریابی اپ موبایل
- کامپوزرهای یادداشت، صدا یا ضبط
- شِل‌های پروتوتایپ برای اپ مصرفی
- پیش‌نمای تنظیمات (تم، پروفایل)
- منوهای اکشن شناور روی دموی لندینگ

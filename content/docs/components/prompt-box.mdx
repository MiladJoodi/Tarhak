## قابلیت‌ها

- **جمع تا نوشتن**: یک ضربه textarea در حال رشد را باز می‌کند. بلور خالی جمعش می‌کند.
- **منوی مدل**: گزینه‌های ویژه با تأخیر می‌آیند. هایلایت زیر اشاره‌گر می‌لغزد.
- **ارسال و صدا**: کنترل ارسال اسکیل می‌گیرد. خالی میکروفون نشان می‌دهد؛ با تایپ، فلش جایش می‌نشیند.
- **نشانهٔ هاور**: روی اشاره‌گر دقیق، فیلد جمع‌شده مدل انتخاب‌شده را با آیکن چرخان نشان می‌دهد.
- **حرکت کمتر**: فنر و چرخش به محو کوتاه تبدیل می‌شوند. کامپوزر همچنان باز و ارسال می‌شود.

## نحوه استفاده

به `@base-ui/react` نیاز دارد. برای منوی مدل `settingGroups` و برای ارسال `onSubmit` بدهید.

```tsx
import PromptBox from "@/components/prompt-box";

export default function Example() {
  return <PromptBox />;
}
```

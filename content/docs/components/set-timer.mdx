## قابلیت‌ها

- **یک سطح شکل‌پذیر**: قرص جمع‌وجور ← چرخ انتخاب ← پنل اجرا. عرض، ارتفاع و شعاع بین حالت‌ها فنر می‌خورند.
- **چرخ به‌سبک iOS**: چرخ بی‌پایان ۱ تا ۶۰ دقیقه با محو شدن تدریجی بالا و پایین ردیف انتخاب‌شده.
- **پیشرفت محیطی**: خطی از مرکز بالا، ساعت‌گرد دور مستطیل گرد می‌دود و با اتمام زمان خالی می‌شود.
- **مکث و ادامه**: شمارش و حاشیه روی مکث می‌ایستند. برچسب بین مکث و ادامه جابه‌جا می‌شود.
- **لغو تمیز**: به قرص برمی‌گردد بدون اینکه حاشیه ناگهان پر شود.
- **حرکت کمتر**: فنرها و مقیاس به محو شدن کوتاه تبدیل می‌شوند. هر تغییر حالت دیده می‌شود.

## نحوه استفاده

کافی است بگذارید و کلیک کنید. شمارش بر پایهٔ مهلت است؛ حتی اگر تب کند شود دقیق می‌ماند. به `@ncdai/react-wheel-picker` نیاز دارد.

```tsx
import SetTimer from "@/components/set-timer";

export default function Example() {
  return <SetTimer />;
}
```

## کجا استفاده شود

- ویجت تمرکز یا پومودورو
- اپ‌های آشپزی و ورزش
- ابزار جلسه و ارائه
- میانبرهای داشبورد
- نمونه‌های موشن در پورتفولیو

## قابلیت‌ها

- **قوس برچسب‌ها**: عنوان‌ها روی چرخ می‌نشینند؛ انتخاب‌شده در رأس قوس است.
- **قفل عکس**: تصویر بزرگ کنار چرخ با حرکت کراس‌فید می‌شود.
- **کشیدن، چرخ، کلید**: اشاره‌گر، ترک‌پد و پیکان‌ها روی یک آیتم اسنپ می‌شوند.
- **تکانه بعد اسنپ**: پرتاب‌ها ادامه می‌یابند، بعد روی یک نام می‌نشینند.
- **محو لبه**: برچسب‌ها در بالا و پایین قوس محو می‌شوند تا فهرست بریده به‌نظر نرسد.

## نحوه استفاده

آیتم‌ها را با `label` و `image` بدهید (معماری، داخلی، منظر در دمو). صحنهٔ عریض لازم است — عکس + چرخ. این مرورگر کاتالوگ است، نه ویجت کوچک. اگر نام‌ها بلندند، شعاع و تعداد قابل‌دید را تنظیم کنید.

```tsx
import WheelCarousel from "@/components/wheel-carousel";

export default function Example() {
  return <WheelCarousel />;
}
```

## قابلیت‌ها

- **لبهٔ ارگانیک**: منحنی درجه‌دوم SVG روی لبهٔ داخلی متحرک برآمده می‌شود، بعد صاف می‌نشیند.
- **هر دو سمت**: چپ و راست. مسیر آینه می‌شود تا برآمدگی همیشه به داخل باشد.
- **پوستهٔ Vaul**: اورلی، تلهٔ فوکوس و درگ فقط از دسته. Motion اسلاید را می‌راند تا منحنی همگام بماند.
- **حرکت کاهش‌یافته**: اسلاید و مورف مسیر آنی می‌شوند. کشوها باز هم می‌شوند.
- نیاز به `vaul` و `motion`. شیت بصری است، نه روتر.

## نحوه استفاده

`direction` و `curveSide` را هماهنگ کنید. در RTL دکمهٔ «راست» کشو را از سمت شروع باز می‌کند.

```tsx
import CurveDrawer from "@/components/curve-drawer";

export default function Example() {
  return <CurveDrawer />;
}
```

## کجا استفاده شود

- منوی کناری اپ
- پنل یادداشت یا جزئیات
- فیلترهای موبایل
- تنظیمات شناور
- شیت‌هایی که به لبهٔ نرم نیاز دارند

## نحوه استفاده

```tsx
import UndoDelete from "@/components/undo-delete";

export default function Example() {
  return <UndoDelete />;
}
```

## قابلیت‌ها

- حذف ردیف با خروج نرم (لغزش و بلور) و چیدمان فنری بقیهٔ فهرست.
- نوار «بازگردانی» با نوار پیشرفت؛ حدود پنج ثانیه فرصت دارید.
- بازگردانی آیتم را به همان جای قبلی برمی‌گرداند.
- اگر فرصت تمام شود، حذف قطعی می‌شود؛ «بازنشانی» فهرست را پر می‌کند.
- آیکون Hugeicons، RTL، فونت Estedad و کپی فارسی.
- به `motion` و Hugeicons نیاز دارد.

## قابلیت‌ها

- **بادبزن هم‌پوشان**: کارت‌ها مثل تراشه‌های رنگ جابه‌جا می‌نشینند — شکوفه، مه، چمنزار، مرجان.
- **پاپ با هاور**: کارت فعال حدود صد پیکسل بلند می‌شود و کمی اسکل می‌گیرد.
- **کج شدن همسایه**: کارت‌های یک سمت یک‌طور، سمت دیگر طور دیگر کج می‌شوند تا شکاف باز شود.
- **بدون عکس**: پرهای نرم و یک کلمه — حرکت تمام نمایش است.
- **فنر آرام**: هاور نمی‌لرزد؛ تمیز می‌ایستد.

## نحوه استفاده

قطعهٔ هاور است. در بخش عریض دسکتاپ بگذارید؛ لمس همان شکاف را نمی‌دهد. عنوان و پر پاستلی را عوض کنید. هشت کارت دمو است — کمتر هم کار می‌کند، بیشتر شلوغ می‌شود. روی هر کارت لینک نگذارید مگر بخواهید ناحیهٔ کلیک شلوغ شود.

```tsx
import PopTiltCards from "@/components/pop-tilt-cards";

export default function Example() {
  return <PopTiltCards />;
}
```

## کجا استفاده شود

- صفحهٔ اصلی استودیو یا برند
- داستان سیستم رنگ یا پالت
- تیزر فهرست قابلیت
- کاور پورتفولیو بدون عکاسی
- لندینگ نمایشگاه یا مجموعه

## نحوه استفاده

```tsx
import ScrollSplitCards from "@/components/scroll-split-cards";

export default function Example() {
  return <ScrollSplitCards />;
}
```

## قابلیت‌ها

- یک قاب، بعد برش: سه پنل اول صاف‌اند تا یک تصویر واحد خوانده شوند.
- دسکتاپ: پنل‌های بیرونی به چپ و راست می‌روند، بعد روی محور Y می‌چرخند.
- موبایل: همان عکس به سه باند افقی روی هم بریده می‌شود، جدا می‌شود و با فلیپ عمودی (محور X) متن نشان می‌دهد.
- پشت هر پنل: شماره، کیکر، عنوان، متن.
- تصویر خودت: `imageSrc` و سه `items` بده. آیتم اضافه نادیده گرفته می‌شود.

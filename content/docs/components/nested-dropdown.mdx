## نحوه استفاده

```tsx
import NestedDropdown from "@/components/nested-dropdown";

export default function Example() {
  return (
    <div className="flex h-[400px] w-full items-center justify-center">
      <NestedDropdown />
    </div>
  );
}
```

## قابلیت‌ها

- دکمهٔ گرد ۸۰×۸۰ (شعاع ۴۰) با `layoutId` به پنل `bg-card` (شعاع ۲۰) تبدیل می‌شود — همان الگوی `filter-interaction`.
- ردیف‌ها `text-xl`، آیکون ۲۴، پدینگ راحت، `rounded-2xl` و `hover:bg-accent`.
- شاخه‌ها فلش دارند و زیرمنو باز می‌کنند؛ برگ‌ها منو را می‌بندند — بدون رادیو/تیک.
- برگشت از بالای هر زیرمنو؛ Escape برگشت یا بستن.
- بدون سایهٔ سنگین — فقط `border-border`.
- به `motion` و `@hugeicons/*` نیاز دارد.

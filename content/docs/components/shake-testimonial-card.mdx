## قابلیت‌ها

- **لرزش و پرتاب**: کارت جلو قبل از رفتن به پشت پشته می‌لرزد.
- **عمق پشته**: مقیاس و فاصله، دسته را سه‌لایه نشان می‌دهد.
- **موجی و رنگ**: هر نقل‌قول چهره، پس‌زمینهٔ رنگی و تایپ هماهنگ دارد.
- **پخش خودکار**: تایمر جلو می‌برد؛ اگر نخواستید صبر کنید روی پشته کلیک کنید.
- **فنر**: پرتاب نرم می‌نشیند، نه برش ناگهانی.

## نحوه استفاده

آرایهٔ `testimonials` را عوض کنید — نام، نقش، آواتار، نقل‌قول، رنگ‌ها. به فضای مرکزی حدود ۵۰۰px ارتفاع نیاز دارد. پخش خودکار روشن است؛ همان شوخی کار است. برای اثبات اجتماعی مناسب است، نه مطالعهٔ موردی بلند. چهار نقل‌قول کافی است.

```tsx
import ShakeTestimonial from "@/components/shake-testimonial-card";

export default function Page() {
  return (
    <div className="h-[500px] w-full flex items-center justify-center">
      <ShakeTestimonial />
    </div>
  );
}
```

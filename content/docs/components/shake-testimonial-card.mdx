## قابلیت‌ها

- **لرزش و پرتاب**: کارت جلو می‌لرزد، بعد به پشت پشته پرتاب می‌شود.
- **عمق پشته**: مقیاس و فاصله، سه لایهٔ پشت را نشان می‌دهد.
- **سطح جوهر**: هر نقل‌قول رنگ تیره، چهره و تأکید رنگی خودش را دارد.
- **پخش خودکار**: هر چند ثانیه جلو می‌رود؛ روی هاور مکث می‌کند؛ کلیک هم کافی است.
- **حرکت کم**: با `prefers-reduced-motion` فقط جابه‌جا می‌شود، بدون لرزش.

## نحوه استفاده

آرایهٔ `testimonials` را عوض کنید — نام، نقش، آواتار، نقل‌قول و رنگ‌ها. حدود ۵۰۰px ارتفاع می‌خواهد. برای اثبات اجتماعی کوتاه مناسب است، نه مطالعهٔ موردی بلند.

```tsx
import ShakeTestimonial from "@/components/shake-testimonial-card";

export default function Page() {
  return (
    <div className="flex h-[500px] w-full items-center justify-center">
      <ShakeTestimonial />
    </div>
  );
}
```

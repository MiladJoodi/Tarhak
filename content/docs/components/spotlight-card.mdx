## نحوه استفاده

```tsx
import { SpotlightCard } from "@/components/spotlight-card";

export default function Example() {
  return (
    <SpotlightCard theme="dark" className="max-w-[330px]">
      <p>محتوای کارت</p>
    </SpotlightCard>
  );
}
```

## قابلیت‌ها

- نورافکن شعاعی که اشاره‌گر را با نرمی دنبال می‌کند.
- شکل `circle` یا `beam` (نور از لبهٔ بالا مثل نورافکن صحنه).
- درخشش لبه نزدیک اشاره‌گر (`borderGlow`).
- `proximity` برای روشن شدن کارت‌های هم‌جوار با یک نور مشترک.
- `ambient` برای حرکت آهستهٔ نور در صفحه‌های لمسی.
- `flare` هنگام فشردن، نور را کمی بزرگ‌تر و روشن‌تر می‌کند.
- تم `dark` / `light` و رنگ سفارشی با `spotlightColor`.
- RTL و محتوای فارسی در پیش‌نمایش پیش‌فرض.

## Props اصلی

| Prop | پیش‌فرض | توضیح |
|------|---------|--------|
| `intensity` | `0.15` | روشنایی سطح |
| `spotlightSize` | `240` | شعاع نور (px) |
| `softness` | `0.7` | نرمی محو شدن |
| `shape` | `circle` | `circle` یا `beam` |
| `borderGlow` | `0.6` | درخشش لبه |
| `proximity` | `80` | فاصلهٔ شروع نور بیرون از کارت |
| `smoothing` | `0.3` | تأخیر دنبال‌کردن اشاره‌گر |
| `theme` | `dark` | سطح و حاشیه |

## کجا استفاده شود

- کارت پروفایل فریلنسر
- کارت ویژگی در لندینگ تیره
- شبکهٔ کارت‌هایی که نور مشترک دارند

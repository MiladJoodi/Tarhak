## قابلیت‌ها

- **میز چاپ**: حاشیهٔ سفید، زیرنویس دست‌نویس، کمی چرخش از همان اول.
- **کشیدن با کج شدن**: کارت‌ها با ضربه کج می‌شوند، بعد آرام می‌نشینند.
- **آوردن به جلو**: چاپی که می‌گیرید بالای بقیه می‌آید.
- **چسب و پونز**: واشی اختیاری و پونز تا بعضی شات‌ها به دیوار چسبیده حس شوند.
- **محدودیت عرصه**: کشیدن داخل گالری می‌ماند تا چاپ‌ها از بوم نپرند.

## نحوه استفاده

چند `PolaroidCard` داخل گالری بگذارید. عکس و زیرنویس کوتاه لازم است. زمین بازی است، نه لایت‌باکس — جابه‌جا می‌کنند، زوم نمی‌کنند. صحنهٔ بزرگ و روشن بدهید. در ستون تنگ نگذارید.

```tsx
import PolaroidDrag from "@/components/polaroid-drag";

export default function Example() {
  return <PolaroidDrag />;
}
```

## قابلیت‌ها

- **مورف گوشه**: از تصویر-در-تصویر کوچک شروع می‌شود و به پخش‌کنندهٔ بزرگ‌تر نرم می‌شود.
- **حلقهٔ همیشه روشن**: پخش خودکار و بی‌صدا پیش‌فرض تا بدون صدای بلند روی صفحه بماند.
- **کروم هاور**: پخش، بی‌صدا و بزرگ‌نمایی با هاور روی قاب ظاهر می‌شوند.
- **نوار اسکراب**: نوار پیشرفت را بکشید تا جابه‌جا شوید؛ زمان کنارش است.
- **کلید بزرگ‌نمایی**: بدون ترک صفحه به اندازهٔ سخاوتمندانه‌تر کشیده می‌شود.

## نحوه استفاده

`title`، منبع ویدیو و `defaultMuted` را عوض کنید. گوشه با `end`/`bottom` ثابت است تا در RTL درست بنشیند.

```tsx
import CornerVideo from "@/components/corner-video";

export default function Example() {
  return <CornerVideo />;
}
```

## کجا استفاده شود

- تور محصول روی لندینگ
- دمو کوتاه در مستندات
- ویدیو پشتیبانی گوشه‌ای
- پیش‌نمایش ویژگی در آنبوردینگ
- تبلیغ کمپین بدون مسدود کردن محتوا

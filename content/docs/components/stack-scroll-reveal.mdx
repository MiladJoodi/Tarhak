## نحوه استفاده

```tsx
import StackScrollReveal from "@/components/stack-scroll-reveal";

export default function Example() {
  return <StackScrollReveal />;
}
```

## قابلیت‌ها

- ویوپورت چسبان: مسیر بلند پشته را روی صفحه نگه می‌دارد تا هنگام اسکرول بماند.
- اسکرول همان اسکرابر است: `useScroll` پیشرفت را به `y`، `rotateX`، `scale` و شفافیت هر کارت وصل می‌کند.
- پشتهٔ پوسته‌کن: کارت‌های بعدی پشت می‌مانند؛ کار قبلی بلند می‌شود، کج می‌شود و محو می‌شود تا نوبت بعدی برسد.
- کارت‌های دو بخشی: شماره، عنوان و توضیح روی تصویر تیره.
- پیش‌فرض لندینگ: بخش پایانی آماده است — آرایهٔ `CARDS` را با کار خودتان عوض کنید.

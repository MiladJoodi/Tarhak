## قابلیت‌ها

- **آماده تا مسلح**: یک ضربه دکمهٔ نرم را به حالت قرمز «حذف» تبدیل می‌کند.
- **حلقهٔ شمارش**: تایمر پایین می‌آید تا ضربهٔ تصادفی فرصت برگشت داشته باشد.
- **لغو درجا**: همان کنترل «لغو حذف» می‌شود — بدون مودال اضافه.
- **مورف کاراکتر**: برچسب‌ها با محو کوتاه عوض می‌شوند تا یک دکمه حس شود، نه دو تا.
- **قفل هنگام انیمیشن**: وسط انتقال کلیک نادیده گرفته می‌شود تا دوبار اجرا نشود.

## نحوه استفاده

برای حذف حساب، سطل زباله یا هر کاری که برگشتش سخت است. پایان شمارش را به حذف واقعی وصل کنید. دور از CTAهای اصلی نگه دارید. متن و مدت در خود کامپوننت است — `deleteText` / `cancelText` / شمارش را آنجا عوض کنید.

```tsx
import DeleteButton from "@/components/delete-button";

export default function Page() {
  return <DeleteButton />;
}
```

## کجا استفاده شود

- تنظیمات حساب و تیم
- تأیید سطل زباله یا آرشیو
- لغو اشتراک صورتحساب
- عملیات مخرب ادمین
- حذف فایل یا پروژه در داشبورد

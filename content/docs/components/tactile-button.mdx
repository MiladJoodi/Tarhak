---
title: Tactile Button
description: راکر شیشه‌ای مایع که با فشار داخل چاهش کج می‌شود.
---

## نحوه استفاده

```tsx
import TactileButton from "@/components/tactile-button";

export default function Example() {
  return <TactileButton />;
}
```

## قابلیت‌ها

- فشار راکر: درپوش با فنر کج می‌شود و داخل چاه فرو می‌رود.
- درخشش شیشه: هایلایت و سایهٔ داخلی تا حس سوئیچ فیزیکی بدهد.
- دانهٔ LED: نشانگر شیشه‌ای با هاور و فشار روشن می‌شود (آبی، سبز، کهربایی، قرمز یا تخته‌سنگی).
- اندازه‌ها: `sm`، `default` و `lg`. با `fullWidth` کش می‌آید.

---

## قابلیت‌ها

- **placeholder حرف‌به‌حرف**: «هر چیزی جستجو کنید...» و «تولید تصویر» با یک ورق کوچک سه‌بعدی وارد می‌شوند.
- **آیکون به‌عنوان حالت**: روی آیکون ابتدایی بزنید تا preset عوض شود.
- **ارسال همچنان هست**: پیکان سمت چپ برای خود کوئری.
- **خالی در برابر تایپ‌شده**: انیمیشن placeholder فقط وقتی فیلد خالی است.
- **نوار فشرده**: یک فیلد گرد، نه کل پالت دستور.

## نحوه استفاده

به‌عنوان کنترل پرامپت یا جستجو استفاده کنید. `placeholderOptions` را برای حالت‌های بیشتر ویرایش کنید. برای تعویض باید روی آیکون کلیک شود؛ تایپ یک ورودی عادی است. در هدر یا نوار AI بگذارید. وقتی کسی وسط جمله است، placeholder را خودکار پخش نکنید.

```tsx
import InputSwitch from "@/components/morphing-input";

export default function Page() {
  return <InputSwitch />;
}
```

## کجا استفاده شود

- نوار پرامپت AI
- جستجوی سایت در هدر
- ابزار تولید تصویر یا حالت ترکیبی
- جستجوی شبیه دستور در مستندات
- دموی محصول «یک باکس»

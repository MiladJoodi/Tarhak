## قابلیت‌ها

- **جستجوی در حال رشد**: روی ذره‌بین بزنید؛ قرص به فیلد متن واقعی باز می‌شود.
- **تراشه‌های دسته**: محبوب و علاقه‌مندی‌ها کنارش با رنگ و آیکن خودشان می‌نشینند.
- **محو هنگام جمع‌شدن**: عرض، شفافیت و بلور با هم نرم می‌شوند تا ناگهان بسته نشود.
- **بستن واضح**: بعد از باز شدن جستجو، ضربدر برای جمع کردنش ظاهر می‌شود.
- **یک ردیف**: جستجو و فیلترها یک ارتفاع نوار ابزار دارند.

## نحوه استفاده

در هدر یا نوار مرور بگذارید. آرایهٔ `TABS` را برای دسته‌های بیشتر ویرایش کنید. به ردیفی نیاز دارد که بتواند رشد کند — به عرض ثابت ۴۰px قفل نکنید. با لیست نتایج جفت کنید؛ این کنترل است، نه گرید.

```tsx
import DiscoverButton from "@/components/discover-button";

export default function Page() {
  return <DiscoverButton />;
}
```

## کجا استفاده شود

- هدر مارکت‌پلیس یا کاتالوگ
- نوار مرور دستور، موسیقی یا عکس
- صفحات «کشف» جامعه
- جستجوی مستندات با تراشهٔ موضوع
- صفحه‌های کاوش شبیه فروشگاه اپ

## قابلیت‌ها

- **یک ردیف در هر لحظه**: باز کردن یک ادعا بقیه را می‌بندد تا داستان متمرکز بماند.
- **کراس‌فید تصویر**: تصویر بزرگ کنار با ردیف فعال عوض می‌شود — نه یک بندانگشتی کوچک.
- **نشان‌های شماره‌دار**: 01–05 کنار عنوان‌ها می‌نشینند تا توالی مثل تور محصول حس شود.
- **پخش خودکار با مکث**: می‌تواند خودش لیست را بپیماید، بعد با هاور بایستد.
- **گام صفحه‌کلید**: با فلش‌ها بین ردیف‌ها بروید بدون شکار ماوس.

## نحوه استفاده

بهترین با ۴ تا ۶ آیتم که هر کدام عنوان، ادعای کوتاه و عکس دارند. لایه‌آوت عریض می‌خواهد تا تصویر و لیست کنار هم بنشینند. مکث-با-هاور از قبل هست — پخش خودکار را برای صفحهٔ اصلی روشن و برای صفحهٔ شبیه مستندات خاموش بگذارید.

```tsx
import Accordionos from "@/components/accordionos";

export default function Example() {
  return <Accordionos />;
}
```

## کجا استفاده شود

- تور قابلیت‌های صفحهٔ اصلی با عکاسی
- بخش‌های توانمندی آژانس
- بلوک‌های «چطور کار می‌کند» محصول
- مطالعات موردی معماری یا داخلی
- خط‌آپ کنفرانس یا جشنواره

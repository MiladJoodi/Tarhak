```tsx
  return <SaveButton />;

```

## قابلیت‌ها

- سه وضعیت: آماده، در حال ذخیره و موفق در یک کنترل.
- تغییر حرف‌به‌حرف: کاراکترها با محو و مقیاس عوض می‌شوند — نه فقط اسپینر.
- نقطهٔ گوشه: نشانگر کوچک وقتی کار می‌کند یا تمام شده.
- غیرفعال وسط کار: تا ذخیره تمام نشده دوباره نمی‌شود زد.
- برگشت به آماده: بعد از موفق دوباره می‌توانید ذخیره کنید.

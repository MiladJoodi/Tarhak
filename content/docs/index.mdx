**useLayouts** یک مجموعه رایگان از کامپوننت‌های متحرک برای React است؛ از تب و دکمه گرفته تا گالری و تعاملات کوچک رابط کاربری. کامپوننت را به پروژه‌تان اضافه می‌کنید و کدش کاملاً در اختیار خودتان است.

## وقتی رابط کاربری بی‌روح بود

یادم هست یک شب، صفحه محصول را تمام کردم. هاورها درست کار می‌کردند، انیمیشن‌ها نرم بودند و هیچ مشکلی هم وجود نداشت.

اما وقتی خودم با صفحه کار می‌کردم، چیزی کم بود.

رابط کاربری کار می‌کرد، ولی حس نمی‌داد.

### چه چیزی ساخته بودم؟

همان چیزهایی که معمولاً در یک UI Kit می‌بینیم:

بزرگ شدن یک عنصر هنگام هاور، محو شدن هنگام باز شدن و چند ترنزیشن تکراری که روی بیشتر بخش‌های صفحه استفاده می‌شوند.

همه‌چیز درست بود، اما زیادی قابل‌پیش‌بینی بود.

### چه چیزی می‌خواستم؟

می‌خواستم تعامل‌ها کمی بیشتر از یک تغییر ساده در CSS باشند.

دکمه‌ای که هنگام کلیک واکنش نشان بدهد. کارتی که به حرکت نشانگر واکنش نشان دهد. حذف شدن یک آیتم طوری باشد که واقعاً حس شود چیزی از صفحه حذف شده.

می‌خواستم رابط کاربری نشان بدهد که به کاری که کاربر انجام می‌دهد واکنش دارد.

برای همین شروع کردم به ساختن این کامپوننت‌ها با Motion و Tailwind، یکی‌یکی.

بعد تصمیم گرفتم کدشان را در یک ریپو قرار بدهم تا دیگران هم بتوانند آن‌ها را بردارند، تغییر دهند و برای پروژه خودشان استفاده کنند.

## این چیست؟

نه یک پکیج بسته که نتوانید داخلش دست ببرید، نه یک تم آماده که مجبور باشید خودتان را با آن هماهنگ کنید.

کامپوننت را انتخاب می‌کنید، با CLI به پروژه اضافه‌اش می‌کنید و کدش داخل پروژه خودتان قرار می‌گیرد.

می‌توانید انیمیشنش را تغییر دهید، ظاهرش را عوض کنید، بخشی از آن را حذف کنید یا حتی کاملاً مطابق نیاز خودتان بازنویسی‌اش کنید.

از اینجا به بعد، کد متعلق به شماست.

## نصب

این پروژه از Registry مربوط به **FarsiUI** استفاده می‌کند.

یک‌بار Registry را به پروژه اضافه کنید و بعد کامپوننت‌های موردنظرتان را با نامشان نصب کنید.

### افزودن Registry

در فایل `components.json` پروژه:

```json
{
  "registries": {
    "@uselayouts": "https://uselayouts.com/r/{name}.json"
  }
}
```

### انتخاب کامپوننت

برای مثال:

```bash
npx farsiui@latest add @uselayouts/discrete-tabs
```

### مدیرهای پکیج

با pnpm، yarn و bun هم می‌توانید همین کار را انجام دهید:

```bash
pnpm dlx farsiui@latest add @uselayouts/discrete-tabs

yarn dlx farsiui@latest add @uselayouts/discrete-tabs

bunx --bun farsiui@latest add @uselayouts/discrete-tabs
```

چند کامپوننت را هم می‌توانید هم‌زمان اضافه کنید:

```bash
npx farsiui@latest add @uselayouts/delete-button @uselayouts/status-button
```

پروژه شما باید React و Tailwind داشته باشد. Motion و سایر وابستگی‌های موردنیاز هر کامپوننت هم هنگام نصب اضافه می‌شوند.

## یکی را باز کنید و تغییرش دهید

با این کامپوننت‌ها مثل یک محصول نهایی رفتار نکنید.

آن‌ها نقطه شروع هستند.

انیمیشن را تغییر دهید، سرعتش را کم یا زیاد کنید، ظاهرش را با طراحی خودتان هماهنگ کنید، پراپ‌ها را تغییر دهید یا هر بخشی را که نیاز ندارید حذف کنید.

مزیت اینکه کد داخل پروژه خودتان قرار می‌گیرد همین است: برای تغییر دادن آن لازم نیست منتظر کتابخانه بمانید.

## انیمیشن باید دلیل داشته باشد

هر انیمیشن باید یک کاربرد مشخص داشته باشد؛ مثلاً ایجاد بازخورد، نشان دادن تغییر وضعیت یا کمک به درک بهتر جریان کار.

اگر یک حرکت فقط برای جذاب‌تر شدن اضافه شده و چیز بیشتری به تجربه کاربر اضافه نمی‌کند، احتمالاً بهتر است حذف شود.

این کامپوننت‌ها بیشتر برای لحظه‌هایی ساخته شده‌اند که یک رابط کاربری کاملاً ثابت نمی‌تواند به‌اندازه کافی منظورش را منتقل کند؛ مثل انتظار، حذف شدن، جابه‌جایی و کشیدن عناصر.

## از کجا شروع کنیم؟

### مرور کامپوننت‌ها

صفحه [**مرور**](/browse) محل خوبی برای شروع است.

کامپوننت‌ها را ببینید، روی آن‌ها حرکت کنید و هرکدام را که به کارتان می‌آید باز کنید.

### صفحات کامپوننت

هر صفحه [**کامپوننت**](/docs/components/pricing-card) شامل پیش‌نمایش زنده، دستور نصب و سورسی است که با دستور `add` وارد پروژه شما می‌شود.

## این پروژه برای چه کسانی است؟

### اگر به‌تنهایی روی محصول کار می‌کنید

اگر نمی‌خواهید برای هر تعامل کوچک رابط کاربری را از صفر بسازید، می‌توانید از این کامپوننت‌ها به‌عنوان نقطه شروع استفاده کنید و وقتتان را روی خود محصول بگذارید.

### اگر تیمی کار می‌کنید

کامپوننت را وارد پروژه کنید، با طراحی خودتان هماهنگش کنید و در صورت نیاز کدش را تغییر دهید.

اینجا قرار نیست یک کامپوننت غیرقابل‌تغییر تحویل بگیرید؛ قرار است کدی داشته باشید که بتوانید خودتان کنترلش کنید.

## رایگان می‌ماند

هدف این پروژه این است که یک نقطه شروع خوب برای ساخت رابط‌های کاربری متحرک در اختیار همه باشد.

اگر سؤال یا پیشنهادی دارید یا دوست دارید در پروژه همکاری کنید، از صفحه [**تماس**](/contact) با ما در ارتباط باشید.

اگر کامپوننتی به کارتان می‌آید، بردارید، تغییرش دهید و در پروژه خودتان استفاده کنید.
